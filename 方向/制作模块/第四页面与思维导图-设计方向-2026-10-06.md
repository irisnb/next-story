# 第四页面与思维导图 v0·设计方向（2026-10-06）

> 来源：designer lane（gpt-6-astra）2026-10-06 产出，依据当日交付物定义与共识文档；**仅为设计方向，未实现、未做真机视觉验证**。实施细节以各 change 的设计与验收为准。
> 设计师首先点出的两个结构性要点：**启用的是整条链路及其版本，卡只是零件；固定底座由所有链路共用，不能画成某张卡下面的可改节点。**

## 一、两个方向共用的页面原则

导航保持现有顺序，在末尾增加第四页：

```text
写作    文件管理    设置    制作模块
                            ■ 当前页
```

第四页独立占用主内容区，制作助手固定在本页内。日常 AI 面板及其浮动讨论不覆盖制作页面；返回写作后仍可继续原来的讨论。

页面顶部常驻一条简短状态：

> 当前链路：情节探索 · 第 3 版　｜　所有作品共用　　[停用]
> 从下一轮开始使用；正在生成的回复沿用发起时的版本。

没有启用链路时显示：当前未启用链路，使用日常陪想。

这条状态不随用户浏览别的链路而变化。**查看、制作、启用是三件不同的事。**顶栏作品名可保留作环境提示，但本页必须标注「所有作品共用」；保存与 AI 面板按钮建议在本页隐藏，避免误解。

视觉衔接（依据 styles.css）：沿用思源黑体（正文 15–16px、辅助 13–14px）；白底浅灰分区、`#2743e0` 蓝表主操作与选中；主区域 2px 结构线、内部细分隔；2–4px 小圆角、硬边偏移阴影仅用于浮层；间距 8/16/24px 三档；状态以文字为主颜色为辅（黄＝草稿未启用、红＝错误）；动效只保留悬停／按下／展开，导图不播放流动光点或「思考路径」动画。关键状态用正常对比度，不作次要淡化。深色模式需后续设计稿另核，不能假定现有令牌直接适配。

## 二、推荐方向：三栏并列，边制作边检视

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 写作    文件管理    设置    [制作模块]                                   │
├────────────────────────────────────────────────────────────────────────┤
│ 当前链路：情节探索 · 第3版   所有作品共用                     [停用]     │
├───────────────┬────────────────────────────┬───────────────────────────┤
│ 链路库        │ 正在查看：情节探索         │ 制作助手                  │
│ [新建链路]    │ [第4版 草稿 ▾] [版本记录] │ 正在制作：情节探索        │
│ 情节探索      │ 思维导图（组装结构）       │ 要求卡：反差与反转        │
│ 当前启用 第3版│ ┌ 链路可变区 ──────────┐ │ 对话正文                  │
│ 有第4版草稿   │ │ 要求类插槽           │ │ [查看本次草稿][查看试问]  │
│ 另一条链路    │ │ └ 反差与反转卡       │ │                           │
│ 未启用        │ └──────────────────────┘ │ 说说希望怎样调整……        │
│               │ ┌ 固定底座 · 所有链路共用┐│ [输入框]          [发送]  │
│               │ │ 红线/骨/工具/材料规则 │ │                           │
│               │ └──────────────────────┘ │                           │
│               │ 卡片检视（点卡后展开）     │                           │
├───────────────┴────────────────────────────┤                           │
│ 正在查看第4版草稿，尚未启用 [试用] [启用此链路版本]                     │
└───────────────────────────────────────────┴───────────────────────────┘
```

布局比例：链路库约 220px，制作对话约 380–420px，中间检视区用剩余宽度；左右不做自由漂浮窗口。三块职责：**链路库找成品**（名称／当前启用版本／有无新草稿；点击只查看）；**中间看成品与确定使用**（导图上方固定显示所查链路与版本；启用按钮写明作用对象）；**制作对话做零件**（新建链路只需简单命名或接受助手建议，不先填配置表）。点卡后在中间区下方展开检视面板，不再挤第四栏、不盖住制作对话。浏览另一条链路时制作对话不悄悄换对象（点「请制作助手修改」才切换）。

窄窗口两级收拢：中等宽度时链路库收为按钮；更窄时本页内切「结构检视／制作对话」，顶部状态条仍常驻；切换保留输入与浏览位置。

备选方向二（上下排列：上半结构检视、下半制作对话）阅读行长更宽、窄窗口更自然，但矮窗口下频繁滚动、长对话难回看，且「边反馈边看改动」不如并列直接——故未推荐。

## 三、思维导图 v0 的具体表达

有包含关系的结构图，固定排版，普通滚动。标题下一句说明：

> 展示链路的组装结构与适用条件，不代表 AI 内部思考过程。

```text
┌ 链路可变区 ──────────────────────────────┐
│ 要求类插槽：想让 AI 多做什么、别做什么      │
│   └── [反差与反转卡 · 第2版]              │
│        适用：探索情节可能性时               │
│        不适用：只讨论台词情绪时             │
└──────────────────────────────────────────┘
                 │ 共用以下固定底座
┌ 固定底座 · 所有链路共用 · 不可修改 ────────┐
│ 红线 │ 骨（底线立场） │ 工具 │ 材料规则    │
└──────────────────────────────────────────┘
每轮另行加入：用户问题、当轮材料、当轮入口
```

要点：**固定底座不属于卡片的下一级**（包含框表「属于」，无箭头短线表「共用」）；**不用步骤编号、执行箭头、先后动画**（避免暗示卡片排列＝模型执行顺序）；第一版只展示要求类插槽，姿态／背景／方式不放灰色占位框也不出现「解锁」入口。底座四项展开为只读说明（红线／骨／工具／材料规则各一句），无修改或开关控件。

## 四、状态、卡片检视与制作流程

三态三个位置表达，不用单一高亮承担全部含义：

| 位置 | 示例 | 含义 |
|---|---|---|
| 页面状态条 | 当前链路：情节探索 · 第3版 | 下一轮日常陪想将使用什么 |
| 链路库选中行、导图标题 | 正在查看：情节探索 · 第4版草稿 | 用户此刻在看什么 |
| 制作对话标题 | 正在制作：情节探索／反差与反转卡 | 当前反馈会修改什么 |

卡片显示「已装入此版本／草稿／历史版本」，不写「正在执行」。卡片检视面板含五项：身份（卡名／插槽／版本／链路版本）、何时用（适用与不适用）、怎么做（完整正文，不能只剩助手概括）、本版变化（相对上一版）、试问记录（本版试问、带卡／不带卡结果、用户反馈；未试用明确写「尚无试问记录」）。主操作＝「请制作助手修改」「查看试问记录」；卡片上不设独立全局启用开关，**启用始终落在链路版本上**。

制作过程用短状态提示，不做长向导：口述要求 → 适量澄清 → 草稿 → 过目试问 → 真实试用 → 反馈改卡 →（明确）启用。试问先供用户查看调整再点「开始试用」；试用区展示所用链路版本、试用作品与关注文档，并说明「试用通过日常陪想读取获准材料；制作助手不直接读取作品」；补读授权由真实链路呈现既有流程。试用不切换全局当前链路，结果与所试版本绑定。启用用具体文字承接（如「启用‘情节探索 · 第4版’，替换当前第3版；所有作品的下一轮提问开始使用」）；普通「这版不错」不得被静默推断为启用；保存失败不得显示已保存／已启用。版本记录完整可达；旧版只读；回退是独立明确动作；停用后回到日常陪想，链路、版本与试问档案保留。

## 五、v0 交互边界

**包含**：新建／查看链路；明确切换当前链路、停用；展开收起插槽与底座说明；点卡检视；经制作对话建卡改卡、看草稿与试问结果；看历史版本与证据、明确回退；键盘可达、焦点可见；空库直接引导口述（「说说你希望 AI 多做什么、少做什么」），不要求先学导图。

**不包含**：拖拽节点、拉线、自定义执行顺序、条件分支、循环、多助手编排；无限画布、缩略地图；卡片上手写整份配置；修改固定底座、按链路开关公共能力；姿态／背景／方式插槽；AI 面板快捷切换按钮；模型内部思维展示、自动冲突解决、自动启用草稿。

## 六、最容易做错的一点

**把「正在看的草稿」画得像「正在生效的配置」。**例如第3版仍在使用、第4版正在试用，用户点开第4版后整图变蓝加绿色「成功」，会被误读为第4版已生效甚至已验证有效。v0 最重要的检视标准：无论点哪张卡、看哪个历史版本，都能立即分清「下一轮用什么／我正在看什么／我正在改什么」。先把这三个事实画清楚，再迭代导图形态。
