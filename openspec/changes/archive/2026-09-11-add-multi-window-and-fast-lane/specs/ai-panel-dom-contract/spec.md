# ai-panel-dom-contract 变更增量

## MODIFIED Requirements

### Requirement: AI 面板必须通过显式 DOM 契约接线

系统 SHALL 为 AI 停靠区与每个讨论窗口提供集中且严格类型化的 DOM 依赖契约，契约包含窗口渲染、折叠、新建对话、错误恢复和临时追问所需的全部节点。窗口初始化 MUST 使用该契约，不得依赖散落的全局节点查询；每个窗口实例 SHALL 从自己的窗口根节点解析契约。

#### Scenario: 每个窗口实例组装契约

- **WHEN** 应用为任一讨论窗口组装 DOM 契约
- **THEN** 系统返回包含全部必需窗口节点的有效契约
- **AND** 该窗口可以仅通过显式契约完成初始化

#### Scenario: 多窗口实例互不共享节点

- **WHEN** 同一作品存在多个讨论窗口
- **THEN** 每个窗口实例使用自己的契约与节点完成接线
- **AND** 窗口接线 MUST NOT 依赖全局唯一 ID 或另一窗口的节点

#### Scenario: 缺少必需节点时明确失败

- **WHEN** 页面缺少窗口契约中的必需节点
- **THEN** DOM 组装在初始化阶段抛出包含缺失节点标识的明确错误
- **AND** 系统不创建部分接线的窗口

#### Scenario: 新建对话控件完成契约接线

- **WHEN** 应用从包含新建对话控件的页面组装 `AppDom`
- **THEN** 窗口契约提供该控件并完成统一初始化
- **AND** 点击控件通过面板 facade 触发新建对话状态迁移

#### Scenario: 空状态隐藏新建对话控件

- **WHEN** 讨论窗口处于空白直接提问状态且没有进行中的请求
- **THEN** 新建对话控件不可见或被隐藏

#### Scenario: 非空状态显示新建对话控件

- **WHEN** 讨论窗口存在临时对话或首轮/追问请求正在进行
- **THEN** 新建对话控件可见且可用
