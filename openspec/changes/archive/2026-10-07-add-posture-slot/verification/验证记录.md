## 一、全量门禁

- `npm run check` **CHECK_EXIT=0（十关卡全绿）**：typecheck → lint → test:frontend → test:reliability → test:driver → test:validation → build → fmt:rust → clippy:rust → test:rust。
- 过程中的集成修正（如实）：
  1. **test:frontend 一处失败**：前端车道把姿态组/副标做成了 dom.ts 解析时合成注入（写域自限），在 FakeElement 夹具（无 ownerDocument）上抛 TypeError，抢先于既有缺节点断言。修正＝回归项目既有架构：静态节点进 index.html（副标＋姿态组，与要求类组同构），dom.ts 纯 requireElement 解析；③时代的负面断言「index.html 不得出现姿态类插槽」按本 change 规格收窄为「背景卡｜方式卡｜解锁」，并补新静态节点正面锚定。
  2. **fmt:rust 一处**：车道测试代码换行不合 rustfmt，`cargo fmt` 后过。
  3. **clippy 一处**：`ai_orchestration.rs` `.then(|| …)` → `.then_some(…)`（unnecessary_lazy_evaluations，-D warnings）。
