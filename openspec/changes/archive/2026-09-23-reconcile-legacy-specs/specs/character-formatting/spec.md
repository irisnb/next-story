# character-formatting 变更增量

> apply 期扩围（用户确认 2026-09-23）：「当前本子」→「当前文档」框架措辞泛化，行为断言语义不动。

## MODIFIED Requirements

### Requirement: 下划线与删除线命令作用于非空选区
系统 SHALL 在下划线与删除线命令上显示未启用、混合、完全启用三种状态，并 MUST 只在当前文档存在至少一个字符的非空选区时启用。未启用或混合状态下点击命令 MUST 向整个选区应用相应标记；完全启用状态下点击命令 MUST 从整个选区移除相应标记。下划线 MUST 支持 `Ctrl+U` 快捷键，且无选区时 MUST NOT 改变当前内容或后续输入格式。

#### Scenario: 混合下划线选区统一加下划线
- **WHEN** 选区中一部分文字有下划线且另一部分没有
- **AND** 用户点击下划线命令
- **THEN** 下划线按钮显示半选状态
- **AND** 点击后选区全部文字成为下划线

#### Scenario: 完全删除线选区统一取消删除线
- **WHEN** 选区全部文字均有删除线
- **AND** 用户点击删除线命令
- **THEN** 系统从选区全部文字移除删除线

#### Scenario: 只有光标时下划线命令禁用
- **WHEN** 当前文档只有插入光标而没有文字选区
- **THEN** 下划线与删除线命令均显示为禁用
- **AND** 按 `Ctrl+U` 不启动后续输入格式
