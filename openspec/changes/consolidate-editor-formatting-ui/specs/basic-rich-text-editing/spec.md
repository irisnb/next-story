# basic-rich-text-editing Specification Delta

## MODIFIED Requirements

### Requirement: 当前本子提供基础富文本工具栏
系统 SHALL 在编辑器左侧提供竖排工具栏与格式抽屉，并 SHALL 让工具栏与抽屉只操作当前本子。左侧竖排工具栏 MUST 提供段落样式、粗体、斜体、下划线、删除线、无序列表、有序列表、撤销、重做、查找入口和格式抽屉开关；段落样式 MUST 包含正文与一到六级标题。格式抽屉 MUST 收纳扩展的字符格式与段落格式控件，并按字符格式、段落格式两节可折叠。

#### Scenario: 左侧工具栏与抽屉只作用于当前本子
- **WHEN** 用户在编辑器左侧使用竖排工具栏或格式抽屉
- **THEN** 命令只作用于当前本子
- **AND** 不改变另一本子

#### Scenario: 格式抽屉按字符与段落分节
- **WHEN** 用户打开格式抽屉
- **THEN** 抽屉按「字符格式」「段落格式」两节展示，且各节可折叠
- **AND** 全部字符与段落格式控件都能在抽屉内找到

#### Scenario: 切换本子后工具栏与抽屉跟随当前本子
- **WHEN** 用户从草稿本切换到正文本
- **THEN** 工具栏与抽屉显示正文本当前选区和历史对应的状态
- **AND** 后续命令不改变草稿本

### Requirement: 窄窗口保持左侧工具栏与抽屉可用
系统 SHALL 在窄窗口保持左侧竖排工具栏与格式抽屉可用，MUST NOT 因窗口变窄而隐藏或禁用任何命令。扩展字符与段落格式控件 MUST 收纳到格式抽屉。收纳 MUST NOT 改变命令的状态、作用范围或选区规则。

#### Scenario: 窄窗口命令仍可用
- **WHEN** 窗口宽度不足以容纳旧的横排工具栏
- **THEN** 左侧竖排工具栏保持显示全部高频命令
- **AND** 扩展格式可从格式抽屉访问

## ADDED Requirements

### Requirement: 左侧工具栏与格式抽屉自动隐藏
系统 SHALL 让格式抽屉在鼠标移出抽屉区域时缓缓收起，并 SHALL 让左侧竖排工具栏在不使用时缓缓隐去、鼠标移到窗口左边缘时重新唤起。自动隐藏 MUST NOT 改变任何命令的状态、作用范围、选区规则或快捷键行为。

#### Scenario: 鼠标移出抽屉自动收起
- **WHEN** 用户打开格式抽屉后把鼠标移出抽屉区域
- **THEN** 抽屉缓缓收起
- **AND** 已选中的格式状态与选区不改变

#### Scenario: 鼠标移到左边缘唤起工具栏
- **WHEN** 左侧竖排工具栏处于隐去状态且用户把鼠标移到窗口左边缘
- **THEN** 工具栏重新浮现
- **AND** 工具栏状态与当前选区一致

#### Scenario: 自动隐藏不改变命令行为
- **WHEN** 工具栏或抽屉处于隐藏或唤起过程
- **THEN** 格式命令的状态、作用范围、选区规则与快捷键保持不变
