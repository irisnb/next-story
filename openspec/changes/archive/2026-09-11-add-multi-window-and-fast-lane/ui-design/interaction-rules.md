# 交互状态与冲突规则

> 配套 change：`add-multi-window-and-fast-lane`
> 用途：直接指导实现。每条规则写明「场景 → 规则 → 界面表现」。
> 前提铁律（不得违反）：关闭窗口停止对应讨论的请求；停止只影响对应讨论；排队先到先服务；布局仅运行期保留、可恢复默认；删除是独立动作、可撤销；AI 永不写作品。

术语：
- **内容层**：讨论内容、请求状态、徽标、按钮可用性（进 reducer，可观察）。
- **显示层**：窗口位置、尺寸、停靠/浮动、层叠（窗口层本地持有，不进 reducer、不持久化）。
- **手势**：一次指针拖动或缩放（pointerdown → pointermove → pointerup）。
- **统一状态词**：只有五个——排队中 / 生成中 / 已停止 / 失败 / 恢复中（外加「已完成」）。任何过渡文案都不是第六种状态。

## A. 通用手势与优先级

| # | 场景 | 规则 | 界面表现 |
|---|------|------|---------|
| A1 | 任意时刻 | 同一时刻只允许一个指针手势（拖动、缩放、文本选择三者互斥）。 | 拖动/缩放期间不响应新的拖动/缩放起点。 |
| A2 | 拖动或缩放开始 | 窗口设置指针捕获（pointer capture），窗口层记录起始几何。 | 光标 `grabbing` / `nwse-resize`；窗口实时跟随。 |
| A3 | 手势进行中，内容层状态变化 | 状态更新**不打断**手势，**不改变窗口几何**。 | 徽标、文字、按钮可用性实时更新；窗口不移动、不跳动、不重排。 |
| A4 | 手势进行中，窗口几何需要重排（新窗口插入、其他窗口关闭） | **拖动中的窗口临时脱离停靠流**（绝对定位），松手后再落位；其余窗口可立即重排。 | 被拖动窗口跟随指针；其他窗口让位；松手后被拖动窗口归位。 |
| A5 | 手势进行中按 Esc | 取消手势，窗口回到手势起始几何（拖动回起始位置，缩放回起始尺寸）。 | 窗口回弹到起点，无状态变化。 |
| A6 | 手势结束 | 释放指针捕获，落定几何；拖动若跨越停靠区边界则切换停靠/浮动归属。 | 停靠区放置区高亮消失；窗口吸附对齐。 |
| A7 | 手势进行中 | 吸附参考线只在靠近阈值（8px）时出现；手势结束即消失。 | 琥珀色虚线 + 「对齐」标签。 |
| A8 | 手势进行中窗口被关闭/删除 | 见 B、C 章；关闭或删除**中断**手势。 | 窗口立即消失，指针捕获释放。 |
| A9 | 缩放与拖动的关系 | **缩放与拖动适用同一套规则**（B 章注明的三点差异除外）：同样不被打断、同样被关闭/切换/删除/恢复默认布局中断、同样 Esc 取消回起点、同样受最小尺寸钳制。 | 缩放取消回起始尺寸；到 300×200 停住。 |

## B. 拖动 / 缩放进行中发生其他事件

> **拖动与缩放适用同一套规则。** 两者都是指针手势，同样「内容更新不打断、关闭/切换/删除/恢复默认布局会中断、Esc 取消回起点」。
> **差异只有三点**：① 吸附参考线只用于**拖动**移动窗口，缩放不对齐其他窗口（缩放仅在触到应用边界时停住）；② **拖动**会改变停靠/浮动归属，缩放只改尺寸；③ **拖动**能拖出/拖回停靠区，缩放不能。

| # | 事件 | 对拖动/缩放的影响 | 界面表现 | 理由 |
|---|------|------------------|---------|------|
| B1 | 生成完成 | 忽略（不打断） | 徽标变「已完成」、内容定格；窗口不动。 | 内容层变化不影响几何 |
| B2 | 生成失败 | 忽略（不打断） | 徽标变「失败」、内容区出现错误说明与「重试」；窗口不动。 | 同上 |
| B3 | 排队开始（名额释放，该讨论轮到） | 忽略（不打断） | 徽标从「排队中」变「生成中」，停止按钮保持；窗口不动。 | 排队状态只在对应窗口呈现 |
| B4 | 用户按「停止」 | 若手势仍在进行：停止**不打断**手势，仅更新状态。 | 徽标变「已停止」，停止按钮隐藏、出现「重试」；窗口不动。 | 停止只影响对应讨论 |
| B5 | 用户按「关闭 ×」 | **中断**手势，释放指针捕获，再关闭窗口。生成中/排队中则先停止该轮。 | 窗口立即关闭；其他窗口不受影响。 | 关闭是显示层动作，必须中断手势 |
| B6 | 用户按「收起停靠区」 | 若被拖动/缩放的是**停靠**窗口：结束手势并回到起点，然后隐藏；若被拖动/缩放的是**浮动**窗口：不影响。 | 停靠窗口消失（状态保留），浮动窗口与手势继续。 | 收起 ≠ 关闭；浮动独立于停靠区 |
| B7 | 另一个窗口被关闭 | 忽略（不打断） | 被拖动窗口继续；其他停靠窗口高度重排。 | 无关窗口不干扰手势 |
| B8 | 切换作品 | **中断**手势；关闭全部窗口。 | 窗口全部消失，面板清空并加载新作品列表；档案保留。 | 作品级切换是全局动作 |
| B9 | 该讨论被删除（从列表发起） | **中断**手势，关闭其窗口并删除。 | 窗口消失；列表移除；停靠区出现撤销提示。 | 删除是独立动作 |
| B10 | 驱动进程丢失，进入恢复 | 忽略（不打断） | 各打开窗口徽标变「恢复中」，输入禁用、停止与重试隐藏；窗口不动。 | 恢复是内容层状态 |
| B11 | 新讨论打开（新窗口插入停靠区） | 忽略（不打断）；被拖动窗口脱离停靠流，插入不重排它。 | 新窗口出现在停靠区底部；被拖动窗口照常跟随指针。 | 见 A4 |
| B12 | 「恢复默认布局」被触发 | **中断**手势；所有窗口回默认停靠与尺寸。 | 窗口回到默认位置；若手势中的窗口浮动则一并归位。 | 布局重置是全局动作 |
| B13 | 窗口吸附/对齐 | 拖动中持续计算；缩放不参与对齐。 | 参考线出现/消失，窗口边缘贴合。 | 吸附属于拖动反馈 |

**分类小结**
- **忽略（不打断手势）**：B1 生成完成、B2 失败、B3 排队开始、B4 停止、B7 他窗关闭、B10 恢复、B11 新讨论、B13 吸附。
- **延迟（松手后处理）**：A4/B11 的停靠区重排。
- **中断手势**：B5 关闭自己、B6 收起停靠区（停靠窗口）、B8 切换作品、B9 删除自己、B12 恢复默认布局。

## C. 操作套操作

| # | 场景 | 规则 | 界面表现 |
|---|------|------|---------|
| C1 | 按「停止」尚未落定时又按「关闭 ×」 | 关闭动作串行：先停止该轮并等待进入**统一终态「已停止」**，再关闭显示；停止与关闭都只作用于该讨论。 | 窗口徽标始终是统一状态词（「已停止」）；内容区可有一行过渡文字「正在停止…」，但它不是第六种状态；随后窗口关闭。 |
| C2 | 关闭后立刻从列表重开同一讨论 | 重开以档案为准，显示最后已保存终态（通常是「已停止」或「中断」）；**不自动重发**、不显示任何「收尾」状态。因为 C1 已保证关闭前停止落定，重开时该讨论通常没有在途请求，输入立即可用。 | 新窗口打开，显示历史与统一终态，输入可用。 |
| C3 | 关闭动作超过合理时间未落定（如 2 秒） | 按「中断」落定后关闭显示，不无限等待。 | 窗口关闭；重开显示「中断」终态。 |
| C4 | 重命名编辑中，生成完成导致列表重排 | **冻结该行的排序与分组**，编辑不被打断、不移动。 | 行停在原位，输入框保持焦点；其他行正常更新。 |
| C5 | 重命名编辑中，列表被收起 | 视为取消重命名（不保存），收起列表。 | 行恢复原标题；列表关闭。 |
| C6 | 删除确认（行内）期间发生其他事件（生成完成、状态变化、另一行 hover） | 确认态**不自动关闭**；只有用户点「取消/删除」、该条目被删除、列表收起、或切换作品时才退出。 | 确认条保持显示；其他更新照常但不动确认条。 |
| C7 | 撤销提示期内再次删除另一条 | 同一时刻**只保留一个可撤销项**；新删除覆盖旧撤销提示。 | 停靠区提示替换为最新一条：「已删除「B」· 撤销」。 |
| C8 | 撤销期内点击「撤销」 | 用内存副本**重新写入档案**并恢复列表条目；**不自动重开窗口**（即使删除前该窗口是打开的或浮动的），避免「撤销一下突然弹窗」的突兀；用户需要时从列表点开。 | 提示消失，条目重现于其分组；窗口不弹出。 |
| C9 | 删除与撤销的实现语义 | 删除 = **立即**从列表与档案移除；前端内存保留一份副本；提示期内「撤销」= 用副本重新写入档案并恢复列表；**提示期结束或应用退出后不可恢复**。 | 删除即时生效；撤销期约 6 秒。 |
| C10 | 并排对照进行中，一方被关闭 | 并排是**瞬时布局关系**，不绑定。关闭一方后另一方回到单窗尺寸（保持其位置）。 | 剩余窗口恢复普通浮动/停靠尺寸，不留空位。 |
| C11 | 并排对照进行中，一方被拖走 | 解除并排关系，两窗各自独立。 | 参考线消失；两窗自由。 |
| C12 | 队列中的请求被「停止」 | 从队列移除，不发起生成，该讨论进入「已停止」。 | 徽标「排队中」→「已停止」；其他排队/生成不受影响。 |
| C13 | 队列中的请求被「关闭窗口」 | 从队列移除并关闭显示。 | 窗口关闭；队列中其他请求前移一位。 |
| C14 | 驱动恢复期间用户按「发送/追问」 | 禁止；恢复完成前不发起新请求。 | 输入框禁用、发送禁用。 |
| C15 | 驱动恢复期间用户按「关闭 ×」 | 允许；只关闭显示，不影响恢复。 | 窗口关闭；讨论仍恢复。 |
| C16 | 驱动恢复期间用户按「停止」 | 无意义，**隐藏停止按钮**（恢复不是生成）。 | 徽标只显示「恢复中」。 |
| C17 | 生成中用户先「停止」再立刻「重试」 | 两次动作都作用于同一讨论；重试重发该轮，讨论内仍至多一轮。 | 徽标「已停止」→「生成中」。 |
| C18 | 失败态用户未重试，直接输入新问题发送 | 视为放弃该失败轮（失败记录保留），开始新一轮。 | 失败轮保留为「失败」记录，新轮追加在下方。 |
| C19 | 「新建对话」时聚焦窗口已是空窗口 | **复用**该空窗口，不新建，避免空窗口堆积。 | 聚焦到该空窗口，不新增窗口。 |
| C20 | 同一讨论从列表再次打开 | 若已有窗口则**聚焦**，不创建第二个窗口（一讨论至多一窗口）。 | 已有窗口置顶并高亮；不新增。 |
| C21 | 删除一个仍有窗口打开的讨论 | 停止其当前轮 → 删除档案 → 关闭其窗口（一次动作）。 | 窗口关闭；列表移除；停靠区出现撤销提示。 |
| C22 | 删除一个正在生成的讨论 | 同上，先停止再删除。 | 窗口关闭；该轮不产生成功轮次。 |
| C23 | 切换作品时，正在重命名某条讨论 | **取消重命名**（不保存），随作品切换清空视图。 | 重命名输入框消失，不写入任何标题。 |
| C24 | 切换作品时，某条讨论处于删除确认中 | **取消删除确认**；该讨论按档案保留在原作品目录，未被删除。 | 确认条消失；不执行删除。 |
| C25 | 切换作品时，停靠区有撤销提示 | **清空撤销项**（该副本只属于原作品，不可跨作品撤销）。 | 提示消失；不可恢复。 |
| C26 | 列表被收起时，某条讨论处于删除确认中 | **取消删除确认**。 | 确认条消失；不执行删除。 |
| C27 | 列表被收起时，停靠区有撤销提示 | **保留撤销提示**：撤销提示属于停靠区层（不依赖列表是否打开），列表收起后仍可见、仍可撤销。 | 提示留在停靠区；点击撤销照常恢复。 |
| C28 | 应用退出时，停靠区有撤销提示 | 撤销机会失效，**不可恢复**（不写入任何持久化的撤销队列）。 | 下次启动无该讨论。 |
| C29 | 搜索过滤时 | **保留天/周/月分组结构**；只显示命中的条目，某分组无命中则不显示该分组标题；置顶区同样保留；全部无命中时显示「无匹配结果」空态。 | 过滤后仍是分组列表，不是一条平铺结果流。 |

## D. 按钮打架检查与状态表

### D1. 规则

| # | 规则 |
|---|------|
| D1.1 | 窗口头右侧动作组顺序固定：`[停止] [⋯] [×]`。停止是**条件显示**，⋯ 与 × **常显**。 |
| D1.2 | 停止只在「排队中/生成中」**显示**，其余状态**隐藏**（不是禁用）。 |
| D1.3 | 「重试」只在「已停止/失败」**显示**（统一叫「重试」，一个动作一个名字）。 |
| D1.4 | 「关闭 ×」在所有状态**可用**（含恢复中）；它是显示层动作，不删除讨论。 |
| D1.5 | 「⋯ 更多」在所有状态可用；菜单项按上下文禁用（见 D3）。 |
| D1.6 | 发送按钮：有草稿且讨论空闲（非生成/排队/恢复）→ 启用；否则禁用（不是隐藏）。 |
| D1.7 | 输入框：生成/排队/恢复中禁用并显示等待文案；已停止/失败/空闲启用。 |
| D1.8 | 行操作（重命名/置顶/删除）只在行 hover 或键盘聚焦时显示；点击行操作**不触发行打开**。 |
| D1.9 | 行主体点击 = 打开/聚焦讨论；行尾按钮点击 = 对应动作（事件不冒泡到行）。 |
| D1.10 | ⋯ 菜单打开时再点 ⋯ = 收起；点菜单外或点 × = 先关菜单再执行目标动作。 |
| D1.11 | 停靠区头按钮（会话列表/新建对话/更多/收起）与窗口头按钮属于不同容器，不重叠；窄宽度下窗口标题先省略，动作按钮 `flex:none` 不压缩。 |
| D1.12 | 窗口被拖到小于最小宽度时由最小尺寸（300×200）阻止，动作按钮不会被压没。 |
| D1.13 | **停靠区头常驻一个 `⋯`**，收纳全局显示层动作（「停靠所有浮动窗口」「恢复默认布局」）；它始终显示，与窗口头 `⋯` 用同一套图标。 |

| 菜单项 | 空闲 | 排队中 | 生成中 | 已停止 | 失败 | 恢复中 | 说明 |

## E. 列表入口行为（核实 + 新规则）

### E1. 现状核实（真实代码行为）

| 位置 | 现有逻辑 | 实际表现 |
|------|---------|---------|
| `src/ai-panel.ts:301` | `conversationListToggleBtn.classList.toggle("hidden", view.conversations.length === 0)` | 「会话列表」按钮在**0 条讨论时隐藏**，第一条讨论开始后才出现 |
| `src/ai-panel-view-model.ts:330` | `newConversationVisible = hasConversation \|\| panelState.request.kind !== "idle"` | 「新建对话」在**完全空白且空闲时隐藏**，出现任何对话或请求后才出现 |

**问题**：空白面板里只剩「收起」，用户开始第一条讨论后两个按钮「突然冒出」，像凭空出现的多余控件。

### E2. 新规则

| # | 场景 | 规则 | 界面表现 |
|---|------|------|---------|
| E2.1 | 任何时刻 | 停靠区头是**常驻工具栏**：「会话列表 / 新建对话 / ⋯ / 收起」**始终显示**，不随讨论数量变化。 | 四个入口从打开面板起就在，位置固定。 |
| E2.2 | 0 条讨论 | 「会话列表」可点，打开列表并显示**空状态**引导；不隐藏按钮。 | 列表显示「还没有讨论…」引导语。 |
| E2.3 | 0 条讨论 | 「新建对话」可点，打开一个空讨论窗口。 | 新空窗口出现。 |
| E2.4 | 1 条 / 多条 | 与 0 条一致；仅列表内容变化。 | 入口不闪、不消失。 |
| E2.5 | 停靠区收起 | 入口移到窄轨上，仍可用。 | 窄轨显示「新建对话 / 会话列表 / 展开 / ⋯」。 |
| E2.6 | 入口与「新建对话」旧逻辑 | **废弃**基于数量的显隐；改用常驻规则。 | 不再出现「突然冒出」。 |

## F. 全局与跨窗口规则

| # | 场景 | 规则 |
|---|------|------|
| F1 | 并发上限 | 达到上限时新请求排队，**只在对应窗口**显示「排队中」，不显示为生成中；名额释放按先到先服务。 |
| F2 | 多窗口同时生成 | 各窗口各自流式、各自停止/重试；增量与终态按讨论身份路由，绝不串台。 |
| F3 | 停靠区收起 | 不停止生成、不清空状态；仅隐藏停靠窗口。浮动窗口不受影响。 |
| F4 | 切换文档 | 不清空讨论、不改变绑定、不关闭窗口。 |
| F5 | 切换作品 | 关闭该作品全部窗口、清空视图、加载新作品列表；档案保留在原作品目录；同时取消重命名与删除确认、清空撤销项（见 C23–C25）。 |
| F6 | 恢复默认布局 | 所有窗口回默认停靠与默认尺寸；不影响讨论与生成；入口常驻于**停靠区头 `⋯` 菜单**（也出现在窗口 `⋯` 菜单）。 |
| F7 | 窗口焦点 | 点击窗口任意位置聚焦/置顶；同一时刻只有一个活动窗口；「始终置顶」默认关闭。 |
| F8 | 迟到结果 | 已删除讨论或已关闭窗口的迟到增量/终态按讨论身份**丢弃**，不污染其他窗口。 |
| F9 | AI 边界 | 窗口内只有纯文本，可选中复制；**没有**任何写回作品的入口。 |

## G. 边界与异常

| # | 场景 | 规则 |
|---|------|------|
| G1 | 拖动越界 | 窗口被钳制在应用窗口范围内。 |
| G2 | 缩放到极小 | 停在最小尺寸 300×200。 |
| G3 | 停靠区窗口过多 | 停靠区整体滚动；建议提示「拖出以并排」。 |
| G4 | 布局异常 | 「恢复默认布局」常驻于停靠区头 `⋯` 菜单，随时可用。 |
| G5 | 空窗口复用 | 「新建对话」时聚焦窗口若为空窗口则复用（见 C19）。 |
| G6 | 同一讨论重复打开 | 聚焦已有窗口，不新建（见 C20）。 |
| G7 | 保存失败 | 在**停靠区层**显示中文提示条（停靠区头下方，打开窗口时也可见），**不依赖列表是否打开**；不打断写作，不静默丢弃。停靠区收起时，在窄轨上显示一个警示小点，展开后可见完整提示。 |
| G8 | 限流/能力不足 | 对应窗口中文提示 + 可手动重试；不自动重试风暴，不伪装成功。 |
| G9 | 窗口关闭 vs 删除 | 关闭只结束显示；删除是独立动作、需确认、可撤销。关闭永不删除讨论。 |
