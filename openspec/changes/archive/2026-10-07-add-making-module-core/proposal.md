# add-making-module-core：制作模块核心（三刀之②）

> 决策依据：《交付物定义-讨论-2026-10-06》§1／§3（交付物与三刀拆分拍板）、《第一刀实施计划-2026-10-06》§2（②范围草案）、《走通一例-反差与反转-2026-10-06》（价值实证＋试用协议）、《第四页面与思维导图-设计方向-2026-10-06》（页面 IA 与三栏方向）、2026-10-06 探索会话四项拍板（见下）。第①刀 `wire-system-prompt-channel` 已归档，链路卡挂载位（`nextstory:chain-cards`，order 20）空段就位，车道满足「一次一个 change」。

## Why

走通一例实证：把反复交代的陪想要求做成可启用的制作成果，能减少「一句提示装不下」的适用判别与结构契约成本，且一句提示本身会诱发过用（Q2-B 失败模式）。第①刀已把信封通道与挂载位建好，本刀把制作模块的核心——页面、制作对话、链路库、装配接线——建起来，让「口语描述→卡→试用→启用→下一轮自动生效」整条链路第一次真实可用。

2026-10-06 探索会话四项拍板（用户确认）：

1. **试问不产生讨论档案、不进日常会话列表**——问答全文只存卡版本绑定的试问证据（全局侧、单一真相源；审查修订后定案）；
2. **试问默认只跑带卡版**——验证增益的对照（带卡／不带卡）是显式手动动作；
3. **「本轮用了哪条链路」最小只读显示进本刀**——对齐「本次参考了什么」轻量模式，不做切换按钮；
4. **制作对话完整保存（B 方案）**——像日常讨论一样可重开、可继续；全局侧存储、随软件走、不进作品文件夹。

## What Changes

- **第四页面「制作模块」**：导航在「写作／文件管理／设置」末尾增加第四页；三区布局（链路库｜结构检视·**简版文字列表式**｜制作对话）＋顶部当前链路状态条；按设计方向文档推荐方向（三栏并列），思维导图 v0（③）之前中间区为文字列表。
- **制作对话＋制作助手**：口语描述 → 适量澄清 → 卡草稿 → 试问先过用户过目 → 走真实日常陪想链路试用 → 反馈改卡 → 用户**显式点头**启用。制作助手全程不读任何作品材料；按用户技术水平说话；每条要求可溯源到用户口述，不自创要求。
- **链路库**：全局多链路、随软件走、不进作品文件夹；管理功能一次建全：建／看／切换当前链路／停用／版本／回退；每次改卡存新版本，历史版本只读可看，试问证据与版本绑定存档。
- **装配接线**：当前链路的要求卡文本注入第①刀预留的 `nextstory:chain-cards` 挂载位（红线之下，次序结构性保证）；当前链路全局一条；切换／停用**下一轮生效**；轮次发起时**冻结**当轮链路版本；崩溃重放按讨论档案记录恢复。
- **逐轮记录**：每轮在讨论档案记「本轮按哪条链路＋哪个版本」——采用**记录级后端自有字段**（按轮次序号索引，前端整档保存不改变；含名称快照，链路日后删除历史记录仍可读）；旧档案无此字段按缺失降级显示。
- **卡结构**：触发描述（含负例）＋正文两段式，长度有硬上限（具体值见 design）；超限／格式问题明确告知，不静默失败。
- **写作页最小只读显示**：讨论窗口「本次参考了什么」面板增加「本轮链路」轻量一行；不新增任何切换按钮。
- **协议扩展（**BREAKING 无——均为可选字段向后兼容**）**：`start_session` 增加可选会话种类（日常／制作助手，缺省日常，制作会话不注册 story 工具）；`send_message` 增加可选 `chain_cards` 字段（当轮冻结的卡文本，缺省 null）。

**明确排除**（不进本刀）：姿态插槽（第二刀第一顺位）、背景卡、方式卡、AI 面板快速切换按钮（归前端 UI 那块）、制作助手读作品（不读；将来真需要再单独定授权）、思维导图 v0（③做）、拖拽节点／自定义执行顺序／条件分支／循环／多助手编排、修改固定底座、按链路开关公共能力、模型内部思维展示、自动冲突解决、自动启用草稿、legacy 一次性生成命令通道（前端已零调用的留存死入口，不接链路装配）。

## Capabilities

### New Capabilities

- `making-module-page`: 第四页面的存在、导航、三区布局、顶部状态条语义（当前链路·版本·所有作品共用·下一轮生效）、简版结构检视（文字列表式）、三态分离（下一轮用什么／正在看什么／正在制作什么）。
- `making-conversation`: 制作对话窗口与制作助手的行为（澄清→草稿→过目试问→真实试用→反馈→显式启用）、不读作品、工具隔离、制作对话完整保存与重开、试问机制（默认带卡单跑、对照显式、不进日常会话列表、证据绑定版本、试用走真实链路）。
- `chain-library`: 链路库的全局存储与生命周期（多链路、版本、启用指针全局一条、切换下一轮生效、轮次发起时冻结、停用与回退、卡结构约束、静默失败禁止）。
- `chain-assembly`: 卡文本注入信封挂载位的装配规则（次序不变式、每轮携带当轮冻结值、在途轮不受打扰、崩溃重放恢复、逐轮记录链路＋版本入讨论档案、写作侧最小只读显示）。

### Modified Capabilities

- `system-prompt-layering`: 「信封内容与次序固定」requirement 修改——链路卡挂载位不再为空，承载当前启用链路当轮冻结的卡文本；红线永居卡上的次序不变式与身份／红线文本不变；崩溃重放 requirement 补充按档案恢复当轮卡。
- `conversation-persistence`: 讨论档案轮次结构增加可选「链路＋版本」字段（serde default，缺失不损坏、不升档案版本号）；链路名称快照随轮保存。

## Impact

- **前端**：`index.html`（新 tab＋新 section）、`src/views.ts`（ModuleId／ModuleViews）、`src/dom.ts`、`src/main.ts`（setModule）、`styles.css`；新制作页面模块（链路库／结构检视／制作对话三区组件）；`ai-window.ts`／`ai-panel-view-model.ts`（「本轮链路」只读行，对齐材料出处显示模式）。
- **Rust 后端**：新链路库存储模块（`app_local_data_dir` 下新全局侧子目录，对齐 `recent_works.rs`／`llm_config` 平铺 JSON＋原子写惯例）；`ai_orchestration.rs` 轮次发起处读链路指针并冻结；`conversation_store.rs` 轮次字段扩展；`dsh_driver.rs` 协议命令扩展（`StartSession` 会话种类、`SendMessage.chain_cards`）；制作助手会话通道（复用常驻驱动进程、独立信封）。
- **sidecar 驱动**：`protocol.json`（两处可选字段＋契约描述）；`driver.mjs`（`createAgentFor` 按会话种类条件注册 story 工具；`send_message` 处理 `chain_cards`——释放重注册 `nextstory:chain-cards` 段，已核实 `dsh-system-prompt` `section()` 返回 disposer、每模型步重组、支持动态变更）；契约测试双向同步。
- **测试与验收**：全量门禁 `npm run check`；协议变更按账本第 21 条真机验收；新页面真机冒烟（CDP 端到端＋用户真实点击）；试问端到端真实模型验证（对齐走通一例协议）。
- **不受影响**：材料装配规则、受控只读边界、按需补读授权流、讨论级隔离、多窗口行为——链路不改变任何读取授权与材料行为。
