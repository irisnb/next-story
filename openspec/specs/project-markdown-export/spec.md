# project-markdown-export Specification

## Purpose

按所选范围把作品已保存内容导出为单个 UTF-8 Markdown 文件：结构映射范围层级、行内格式保真、特殊字符转义防误格式化、不支持的呈现属性降级不丢字符，全程只读并安全写入用户选择的目标。

## Requirements

### Requirement: 按所选范围导出单个 Markdown

系统 SHALL 提供导出 Markdown 能力，范围三选一：当前文档（默认）、作品内任选文件夹（含嵌套子树）、整个作品；SHALL 按既有内容树顺序把所选范围导出为单个 UTF-8 编码的 `.md` 文件，回收站中的节点 MUST NOT 出现。

#### Scenario: 完整范围按树序导出

- **WHEN** 用户对含嵌套文件夹与多文档的作品选择整个作品范围导出 Markdown
- **THEN** 生成一个 `.md`，包含全部活动文档，顺序与内容树一致，层级标题与文档边界清晰

#### Scenario: 默认导出当前文档

- **WHEN** 用户未改动范围直接导出
- **THEN** 生成的 `.md` 仅含当前文档内容，默认文件名为该文档名

#### Scenario: 空范围导出

- **WHEN** 导出范围内没有任何文档（空作品或空文件夹）
- **THEN** 导出成功，文件仅含范围根一级标题

### Requirement: 结构与行内格式的 Markdown 映射

系统 SHALL 按范围根映射层级：整个作品→作品名一级标题（文件夹二级、文档三级）；文件夹→文件夹名一级标题（其文档二级）；文档→文档名一级标题；文档内部标题按自身层级；列表按类型与嵌套层级呈现（有序列表从其 start 起始编号）；粗体、斜体、删除线、链接保留对应 Markdown 标记，下划线用 `<u>` 呈现；文字颜色、fontFamily、fontSize、highlight SHALL 降级为纯文字，MUST NOT 丢失任何字符。正文中会被 Markdown 解释为格式的特殊字符 SHALL 被转义，保证导出文字与原文字面一致。

#### Scenario: 结构与列表映射

- **WHEN** 导出范围含嵌套文件夹、多级标题与嵌套列表
- **THEN** 范围层级标题、列表嵌套与有序列表起始编号在 `.md` 中正确呈现

#### Scenario: 行内格式与链接保留

- **WHEN** 文档包含粗体、斜体、删除线、下划线与链接
- **THEN** `.md` 中分别呈现 `**`、`*`、`~~`、`<u>` 与 `[文字](地址)`，渲染后样式正确

#### Scenario: 特殊字符转义

- **WHEN** 正文文字本身包含 `*`、`#`、`[`、`]` 等会被 Markdown 解释的字符
- **THEN** 导出文件对这些字符转义，渲染后显示为原字面字符，不产生意外格式

### Requirement: 导出只读且使用已保存内容

系统 SHALL 只读取后端已保存的作品内容执行导出，MUST NOT 因导出修改作品任何数据；未保存提示 SHALL 仅在导出范围包含当前文档且该文档存在未保存修改时出现。

#### Scenario: 导出后作品数据字节不变

- **WHEN** 导出 Markdown 成功完成
- **THEN** 作品文件夹内的数据文件与导出前逐字节一致

### Requirement: 用户选择安全的 Markdown 目标路径

系统 SHALL 经统一导出入口与原生保存对话框选择目标路径（默认文件名按范围生成、可修改），取消时 MUST NOT 产生文件与错误提示；写入 SHALL 原子完成，失败清理残留并中文报错。

#### Scenario: 取消与失败

- **WHEN** 用户取消保存对话框，或目标路径不可写
- **THEN** 取消时静默结束、不产生文件；失败时不留残留文件并给出中文错误提示
