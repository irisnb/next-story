**用户报告的旧缺陷（本 E2E 期间确认，登记审计改进候选 5；描述经用户二次澄清修正）**：打开作品的文件夹选择框恢复到「上次打开路径」的子级，无法一步选中作品根目录，须返回上级再选。机理与修复方向见审计补充十九：`selectDirectory` 调用 `open({ directory: true })` 未传 `defaultPath`，初始位置由 Windows ComDlg32「最近使用位置」（按可执行文件持久化）决定，与「上次作品目录」不同源且会被导出保存等动作改写；修复＝持久化上次作品路径并作为 `defaultPath` 传入——对话框定位在该作品文件夹内部，文件夹选择器无高亮项时「选择文件夹」按钮即返回当前文件夹（微软文档与实证确认），一步重开，与候选 4（最近作品列表）共用同一份存储、可同一 change 实施。
