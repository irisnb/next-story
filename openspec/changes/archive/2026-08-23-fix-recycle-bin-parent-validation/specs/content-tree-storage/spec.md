## MODIFIED Requirements

### Requirement: 打开作品时校验内容树结构
系统 SHALL 在打开作品时校验内容树结构，包括节点类型合法性、父子层级合法性、同级名称唯一性以及排列顺序完整性。校验失败时系统 MUST 拒绝打开并显示中文可读错误，且 MUST NOT 用空白或默认结构替代失败内容，也 MUST NOT 覆盖任何原文件。回收站条目的原父级引用 SHALL 可指向当前活动内容树或另一个回收站子树中的文件夹节点；引用不存在或指向非文件夹节点时，系统 MUST 仍拒绝该结构。

#### Scenario: 打开结构合法的内容树
- **WHEN** 用户打开一个内容树结构合法且一致的作品
- **THEN** 系统打开该作品
- **AND** 系统进入编辑器

#### Scenario: 打开结构非法的内容树被拒绝
- **WHEN** 用户打开一个内容树存在非法结构（如文档包含子节点、同级名称重复）的作品
- **THEN** 系统拒绝打开该作品
- **AND** 系统显示中文可读错误
- **AND** 系统不把失败内容替换为空白或默认结构
- **AND** 原文件保持不变

#### Scenario: 删除子项后再删除父文件夹仍可打开
- **WHEN** 用户先把文件夹内的节点删除到回收站，再把该文件夹删除到回收站
- **THEN** 内容树校验接受子项回收站条目指向回收站内父级文件夹的原父级引用
- **AND** 用户可以重新打开作品

#### Scenario: 回收站原父级引用无效时拒绝打开
- **WHEN** 回收站条目的原父级 ID 在活动内容树和所有回收站子树中都不存在，或对应节点不是文件夹
- **THEN** 系统拒绝打开该作品
- **AND** 系统显示中文可读的结构错误
