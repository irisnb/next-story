# 统一多格式导出：PDF ＋ Markdown ＋ Word 重做（三级粒度·所见即所得）

## Why

事项 8 已拍板三格式。2026-10-01 用户确认并给出两条决定性要求：**①导出单位必须是用户可选的三级粒度（文档／文件夹／整个作品）**——现有"把整棵树糊成一个文件"的模式没有实用价值（真实用途是"把某一场/这一集发给别人或存档"）；**②导出观感必须与软件内所见一致（所见即所得）**。Word 导出按同一新标准重做（`project-word-export` 规格同步修订）。教训记入方向账本第 20 条：不做"能实现但不考虑实用性"的功能，提案先验真实使用场景。

技术路线依 2026-10-01 两轮调研（lib-2）：所见即所得 ⇒ PDF 放弃独立排版引擎（typst，已否决），改走**隐藏打印窗口渲染＋WebView2 PrintToPdf**（QuickOutline 生产先例＋官方 API 边界已核）；分页页码用 Paged.js（离线纯前端）；字体捆绑思源黑体（SIL OFL 1.1 允许捆绑/嵌入/子集化）并让编辑器与导出共用同一份，消除跨机器观感漂移。

## What Changes

- **统一导出入口**：现有「导出 Word」按钮升级为一个「导出」对话框——①格式三选一（PDF／Word／Markdown，**默认 Word**）；②范围三选一（**当前文档（默认）**／作品内任选文件夹／整个作品）；③目标文件名（按范围自动建议：`文档名`／`文件夹名`／`作品名`，可改）。三种格式、三种范围共用同一交互。
- **导出 PDF**（新）：隐藏打印窗口用与编辑器一致的 HTML/CSS 渲染**已保存内容**→ Paged.js 预分页（A4、统一边距、底部页码）→ WebView2 PrintToPdf 零边距透传输出单文件。字体、字号、颜色、粗斜下删、对齐、背景与软件内一致；链接可点击；完全离线。
- **导出 Markdown**（新）：同一范围模型，UTF-8 单文件；结构映射（范围根→一级标题，层级递进；列表嵌套与有序起始号；行内格式保留；下划线 `<u>`）；正文特殊字符转义防误格式化；颜色/字体/高亮降级纯文字不丢字符。
- **导出 Word 重做**（修订）：同一范围模型；样式保真升级——正文字体/字号、标题层级字号、文字颜色、段落对齐与编辑器当前呈现对齐（16px↔12pt 同值换算），不再是"默认字体的裸结构"。
- **字体统一**（支撑所见即所得）：思源黑体 CN 子集（常规＋粗体，约 +17MB）随包捆绑，**编辑器正文字体从系统字体栈切换为捆绑思源黑体**，导出渲染用同一份文件——同一内核、同一字体、对齐的 CSS，所见即所得才有确定含义（此改动影响日常编辑器观感，需用户在验收时确认接受）。
- 只读与安全边界沿用既有语义：只导出后端已保存内容（**仅当导出范围包含当前文档且该文档有未保存修改时**提示"导出使用后端已保存版本"）、原子写入不留残file、取消静默、失败中文报错、导出后作品数据字节不变。
- **不改动**：导入方向（批次③④⑤）、导出内容的编辑能力、AI 链路。

## Capabilities

### New Capabilities

- `project-pdf-export`: 按所选范围导出单个 PDF：三级粒度、与软件内一致的排版观感（字体/字号/颜色/强调/对齐）、A4 分页与页码、可点击链接、完全离线、只读与安全写入边界。
- `project-markdown-export`: 按所选范围导出单个 Markdown：三级粒度、结构与行内格式映射、转义规则、降级集合、只读与安全写入边界。

### Modified Capabilities

- `project-word-export`: ①导出范围从"整个作品"改为三级粒度任选（默认当前文档）；②层级标题映射按范围根重定；③内容保真升级为样式对齐编辑器呈现（字体/字号/颜色）；④目标文件名默认值按范围生成。只读、依赖链卫生等要求不变。

## Impact

- **Rust**：`export.rs` 投影层增加范围过滤（文档/文件夹/作品子树）；新 `markdown_export.rs`；`docx_export.rs` 样式保真改造；新 PDF 打印模块（常驻隐藏打印窗口、本地内容加载、事件驱动就绪等待、Paged.js、`with_webview`＋webview2-com 调 PrintToPdf、零边距＋页尺寸对齐设置）；命令层新增/修订（含范围参数，Word 旧命令被替代）。
- **前端**：导出对话框（格式×范围×文件名）；打印窗口页面（复用编辑器 CSS 的打印渲染）；`export-word.ts` 重构并入统一入口；思源黑体经 `@font-face` 注册并切换编辑器正文字体令牌。
- **资源与依赖**：＋思源黑体两字重（约 17MB）＋OFL 许可证文本（tauri.conf resources 与 package:check 登记）；＋Paged.js（离线捆绑，几百 KB 级）；＋`webview2-com` 特性（unsafe COM 边界集中在打印模块）。
- **测试**：Word 测试改造为范围模型（12 个既有测试语义延续）；Markdown 纯函数断言；PDF 自动化到"打印回调成功＋`%PDF` 魔数＋页尺寸"层，观感以真机验收（Edge/Adobe 打开比对软件内呈现）。
- **风险**：unsafe COM 与 WebView2 内部耦合（先例骨架可抄、风险集中单模块）；Paged.js 预分页与 PrintToPdf 的双分页对齐须实机校准（兜底：放弃页内自定义页码，退 @page 原生分页）；安装包 +17MB。
