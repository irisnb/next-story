## 零产品缺陷与已钉死局限

- CDP 全链路**零产品缺陷**。两次「树不可见」均为自动化陈旧态假设（直连 invoke 不触发 UI 刷新），刷新重开即全部呈现——与 Word 冒烟同一教训，非产品缺陷。
- **已钉死的导出侧局限（往返实测发现）**：同文字「下划线＋删除线」组合经导出侧包裹为 `~~<u>…</u>~~`，CommonMark 侧翼规则使闭合 `~~`（前接 `>`、后接字母）无法成为定界符 → 往返后删除线丢失、字面 `~~` 保留（文字零丢失）。专测 `combined_underline_strike_roundtrip_degrades_to_literal_tildes` 钉死现状；修复路径已注明（导出侧调换包裹层级使 underline 最外层），须另立导出 change——本 change Non-Goals 明令不动导出侧。
