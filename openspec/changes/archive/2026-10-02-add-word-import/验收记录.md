## 零产品缺陷

CDP 全链路未发现任何 P0/P1。apply 期间修复的真缺陷均在自动化测试层抓出：docx-rs 读侧不解析脚注引用（改走 document.xml 扫描通道）、前端预检取消未关对话框、Error 字符串前缀污染（des-1 测试抓出）。

## 诚实边界与待用户确认项

- **原生文件选择对话框与预检对话框 UI 无法被合成点击驱动**（与导出验收同类边界：UIA 无窗口）——预检对话框的数据呈现与交互由 22 项 jsdom 测试＋契约测试覆盖。**待用户最终走查**（约两分钟）：文件管理区点「导入 Word 文档」→ 选桌面《导入测试-短剧剧本.docx》→ 看预检卡片 → 确认导入。
- 微软 Word（非 WPS）生成文件实测待用户侧提供一份样本。
- 测试数据留在测试作品 `导出验收-20260901` 内（1 个整文件文档＋文件夹 61 集），可直接打开查看；dev 实例仍在运行。

## 教训（方法论，无需入账本）

真实坐标 Input 点击优于 `el.click()`；文件树行按 `aria-expanded`／expander 控件识别文件夹（行首行文本可能是「▸」）；写作页无常驻树（文档下拉制），验证文档可见性要区分视图。
