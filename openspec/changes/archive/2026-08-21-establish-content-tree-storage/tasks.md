## 4. 校验与崩溃恢复

- [x] 4.1 实现内容树结构校验：节点类型合法性（文件夹 / 文档）、父子层级合法性（文档无子节点、文件夹可含子节点、无循环）、同级名称唯一性、排列顺序完整性（子节点 ID 都存在、无孤儿、无重复）

- [x] 4.4 故障注入测试覆盖两类事务各阶段中断（沿用现有 `SavePhase` 故障钩子模式），断言不出现部分应用的结构
