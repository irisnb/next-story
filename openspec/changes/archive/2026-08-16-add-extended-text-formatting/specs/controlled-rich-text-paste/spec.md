# controlled-rich-text-paste Specification Delta

## MODIFIED Requirements

### Requirement: 外部粘贴只保留支持的文字和格式
系统 SHALL 从外部 HTML 或纯文本中保留可见文字、段落顺序、换行以及可识别的正文、一到六级标题、粗体、斜体、下划线、删除线、文字颜色、背景高亮、链接、无序列表和有序列表（含嵌套列表）。HTML 映射 MUST 将 `p`/`div` 映射为正文、`h1` 到 `h6` 映射为对应标题、`strong`/`b` 映射为粗体、`em`/`i` 映射为斜体、`u`/`ins` 映射为下划线、`s`/`del` 映射为删除线、带合法 `href` 的 `a` 映射为链接标记、内联 `color` 样式映射为文字颜色、`mark` 或内联 `background-color` 映射为背景高亮、`ul`/`ol`/`li` 映射为列表；正文或标题中的每个 `br` MUST 在该位置拆成前后两个同类型块，列表项中的每个 `br` MUST 拆成同一列表内前后两个同级列表项，连续 `br` MUST 产生对应数量的空中间块或空列表项。未知普通容器 MUST 透明保留后代文字；已知普通容器为 `div`、`section`、`article`、`blockquote`、`aside`、`main`、`header`、`footer`、`nav`、`figure`、`figcaption`、`span`、`pre`、`details`、`summary`、`caption`，其它未列入映射的流内容或分组元素 MUST 按普通容器处理。嵌入结构为 `iframe`、`object`、`embed`、`canvas`、`svg`、`video`、`audio`、`picture`、`math`；含可见文字的嵌入结构 MUST 整次拒绝。`img`、`script`、`style`、`meta`、`link`、`head`、`template` MUST 直接忽略。嵌套列表 MUST 按 HTML 的真实层级重建为 `listItem` 内的嵌套 `bulletList` 或 `orderedList`，各层保留其最近 `ul` 或 `ol` 祖先的列表类型；同一 `ol` 的项目被不同类型子列表打断时，打断前出现的同级项目形成一个 `orderedList` 段，打断后出现的同级项目形成一个新的 `orderedList` 段，其后段 `start` MUST 等于原 `ol.start` 加上该 `ol` 在打断前已输出的同级项目数量；`li` 中嵌套列表之后的尾随文字 MUST 追加到该 `li` 自身项目文字，不生成新列表项。合法正整数 `ol[start]`（浏览器解析后的 `ol.start` DOM 属性值，`1 ≤ value ≤ 2^53-1`）MUST 成为该段起始编号；`reversed`、`li[value]` 和非法或超出范围的 `start` MUST 被忽略并等同未指定（从 1 开始）。系统 MUST 丢弃字体、字号、对齐、行距、段间距、缩进、脚本、样式、元数据、样式属性和其它未支持格式或布局，且 MUST 在插入前用当前编辑器 schema 校验归一化结果。

#### Scenario: 从网页粘贴支持与不支持格式的混合内容
- **WHEN** 用户粘贴同时包含标题、粗体、下划线、颜色、字体和正文的网页内容
- **THEN** 编辑器保留标题、粗体、下划线、颜色、正文及可见文字顺序
- **AND** 编辑器不保留字体、字号或其它未支持格式

#### Scenario: 剪贴板只提供纯文本
- **WHEN** 用户粘贴只含纯文本和换行的剪贴板内容
- **THEN** 编辑器按原顺序插入可见文字和换行
- **AND** 插入文字不继承插入位置的字符格式
- **AND** 单行纯文本保留插入位置所属的正文、标题或列表项上下文，多行纯文本按该上下文创建对应同级段落或列表项

#### Scenario: 未知普通容器透明降级
- **WHEN** HTML 使用未支持的普通容器包裹可见文字和支持的子元素
- **THEN** 系统忽略容器本身并按原顺序保留其后代可见文字和支持结构

#### Scenario: 嵌套列表按真实层级保留
- **WHEN** 外部 HTML 包含多层嵌套列表
- **THEN** 系统按 HTML 的真实层级重建为嵌套列表结构
- **AND** 各层列表类型与项目顺序保持不变

#### Scenario: 段落内换行拆为同类型块
- **WHEN** 一个标题包含一个 `br`
- **THEN** 系统按 `br` 位置插入两个相邻同级别标题块
- **AND** 文档不包含 `hardBreak` 或含 LF 的文本节点

#### Scenario: 列表项内连续换行拆为同级项目
- **WHEN** 一个无序列表项包含连续两个 `br`
- **THEN** 系统按原文字顺序生成三个同级无序列表项
- **AND** 中间列表项为空且不产生嵌套列表

#### Scenario: 混合类型嵌套列表按最近类型与层级重建
- **WHEN** 外层无序列表包含起始编号为 3 的内层有序列表
- **THEN** 外层项目成为无序列表，内层项目成为嵌套的从 3 开始的子有序列表
- **AND** 系统忽略 `reversed` 和单项 `value` 覆盖

#### Scenario: 有序列表被不同类型子列表打断后分段保留编号
- **WHEN** 外层有序列表 `start=3` 的项目 A、B 之间含无序子列表 X，B 之后含有序子列表 `start=10` 的项目 Y，最后有同级项目 C
- **THEN** A、B 形成 `start=3` 的有序列表段（编号 3、4），X 形成无序子列表，Y 形成 `start=10` 的有序子列表，C 形成新的有序列表段且 `start=3+2=5`
- **AND** B 中嵌套列表之后的尾随文字追加到 B 的项目文字

#### Scenario: 列表项内嵌套列表后的尾随文字
- **WHEN** 一个有序列表项包含前导文字"前"，其后嵌套无序列表项目"X"，最后有尾随文字"后"
- **THEN** 该列表项文字为"前后"
- **AND** "X" 作为紧随其后的嵌套无序列表项目输出

### Requirement: 外部表格降级为普通文字段落
系统 MUST 将外部表格的每一行转换为一个普通正文段落，将同一行中的相邻单元格用一个 Tab 字符分隔，并 SHALL 保持行和单元格的阅读顺序。单元格内的多个块、列表或换行 MUST 扁平化为以单个空格连接的纯文本（不使用 Tab 或 LF），不产生嵌套段落或列表节点。系统 MUST NOT 创建或保存表格节点。

#### Scenario: 粘贴多行表格
- **WHEN** 用户粘贴一个两行三列的表格
- **THEN** 编辑器插入两个普通正文段落
- **AND** 每个段落中的三个单元格文字按顺序用 Tab 分隔
- **AND** 文档不包含表格节点

### Requirement: 粘贴图片不得进入作品文档
系统 MUST 忽略外部内容中的图片且不得插入图片节点或 `[图片]` 占位。图文混合内容中存在可可靠提取的文字时，系统 SHALL 插入文字并显示中文提示说明图片未被加入；纯图片内容 MUST 不改变文档并显示中文提示。

#### Scenario: 粘贴图文混合内容
- **WHEN** 用户粘贴包含图片和可提取文字的内容
- **THEN** 编辑器只插入可提取文字及支持结构
- **AND** 系统显示图片未被加入的中文提示

#### Scenario: 粘贴纯图片
- **WHEN** 用户粘贴的内容只包含图片
- **THEN** 当前本子内容和历史不发生变化
- **AND** 系统显示无法将图片加入本子的中文提示

### Requirement: 无法保证文字完整时拒绝整次粘贴
HTML 与 `text/plain` 同时存在时，系统 MUST 按以下唯一比较规则验证完整性：两侧都把 CRLF 和 CR 转为 LF、把 NBSP 转为普通空格、删除每行末尾的空格和 Tab；随后两侧各自独立地从最终字符串末尾删除至多一个 LF（若末尾存在 LF 则删一个，不存在则不删；不依赖该 LF 的来源）。HTML 侧每个归一化块投影为一行且不生成列表符号；`text/plain` 中与 HTML 列表项对应的行只可额外去掉一个前导 `• `、`- `、`* ` 或十进制整数加 `. ` 的列表标记。完成上述处理后的行数组 MUST 完全相同，包括空行、Tab、行顺序和行数，否则系统 MUST 拒绝整次粘贴。只有 HTML 而没有 `text/plain` 时，系统 MUST 在遇到含可见文字的嵌入结构且无法按已定义映射处理时拒绝整次粘贴。任何归一化结果未通过 schema 校验时也 MUST 拒绝，保持当前文档和历史不变，并显示中文原因。系统 MUST NOT 插入已知残缺结果。

#### Scenario: HTML 与纯文本不一致
- **WHEN** 同一次粘贴的归一化 HTML 投影缺少 `text/plain` 中的非空可见文字或改变其顺序或段落边界
- **THEN** 系统不插入任何本次粘贴内容
- **AND** 系统显示粘贴失败原因的中文提示

#### Scenario: 只有 HTML 且包含未知嵌入内容
- **WHEN** 剪贴板没有 `text/plain` 且 HTML 包含无法按已定义映射处理并带有可见文字的嵌入内容
- **THEN** 系统拒绝整次粘贴
- **AND** 当前本子内容和历史保持不变

#### Scenario: 归一化结果不符合编辑器 schema
- **WHEN** 粘贴内容归一化后的文档片段未通过当前 schema 校验
- **THEN** 系统拒绝整次粘贴并保持本子不变
- **AND** 系统不把残缺片段加入撤销历史

### Requirement: 本子内复制和剪切保持本轮支持的内容
系统 SHALL 让本子内复制提供与选区对应的纯文本和受控 HTML 表示，并 SHALL 让粘贴回本应用时保留本轮支持的结构与标记。剪切 MUST 只删除当前本子实际选中的内容，并作为可撤销操作处理。

#### Scenario: 复制格式内容到另一本子
- **WHEN** 用户复制包含标题、粗体和列表的选区并粘贴到另一本子
- **THEN** 目标本子保留对应可见文字和本轮支持的格式
- **AND** 源本子不发生变化

#### Scenario: 剪切格式内容
- **WHEN** 用户剪切当前本子的一个格式化选区
- **THEN** 剪贴板获得该选区的纯文本和受控格式表示
- **AND** 当前本子只删除实际选中的内容

## ADDED Requirements

### Requirement: 粘贴提供保留允许格式与粘贴为纯文本两种选项
系统 SHALL 提供明确的粘贴选项：常规粘贴保留允许格式，粘贴为纯文本只插入可见文字并清除一切格式。粘贴为纯文本 MUST 可通过 `Ctrl+Shift+V` 与右键菜单入口触发，并 SHALL 保持插入位置所属的段落或列表上下文，不继承插入位置的字符格式。

#### Scenario: 常规粘贴保留允许格式
- **WHEN** 用户通过常规粘贴插入带允许格式的内容
- **THEN** 系统按白名单保留允许格式
- **AND** 丢弃未支持格式

#### Scenario: 粘贴为纯文本只插入文字
- **WHEN** 用户通过 `Ctrl+Shift+V` 或右键菜单粘贴格式内容
- **THEN** 系统只插入可见文字
- **AND** 不保留任何字符或段落格式
- **AND** 插入文字不继承插入位置的字符格式
