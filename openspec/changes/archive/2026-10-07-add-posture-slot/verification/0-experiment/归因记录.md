# 任务 0 归因记录：姿态卡 2×2 装置实验（2026-10-07）

> 仪器：`sidecar/driver/tests/manual/posture-2x2-experiment.mjs`（手动运行，不进 CI）。
> 方法：直接 spawn 真实驱动（`driver.mjs`）＋真实端点（智谱 coding `glm-5.3`，Key 经凭据管理器 CredRead 注入环境变量、不落盘不回显），每轮全新会话；判据预登记（傲娇标记集，≥2 个不重复标记＝换皮成功；全文落盘供人工复核）。
> 固定项：同卡（傲娇搭档 v1 全文）、同问题（走通一例 Q1）、同材料（主角篇六段／或应用消息复刻）、同模型；红线措辞按格子区分（见下）。

## 一、实验经过与全部结果

### 第一跑：主 2×2（手写短消息；红线一律灰色地带新版）

| 格 | 配置 | 结果（n=2） |
|---|---|---|
| A1 | 身份邻接 × 身份性包装 | 换皮成功 / 换皮成功（标记：哼、笨蛋） |
| A2 | 身份邻接 × 元数据包装 | 换皮成功 / 换皮成功 |
| B1 | 卡段位 × 身份性包装 | 换皮成功 / 换皮成功 |
| B2 | 卡段位 × 元数据包装（＝D/D2 注入方式＋新红线） | 换皮成功 / 换皮成功 |

**意外**：四格全换皮——含 D/D2 同款注入方式。装置层（短消息）无差异，说明 D/D2 的失败另有环境抑制因子。

### 第二跑：红线判决（B2 配置 × 旧红线）

| 格 | 结果 |
|---|---|
| B2old | r1 换皮成功（哼、笨蛋、还行吧）；r2 等待超时（实验脚本 120s 上限的网络偶发，非模型失败，脚本已改 240s） |

**结论**：旧红线三条「不判断」不是抑制因子（至少不是单独的）。

### 第三跑：应用消息判决（复刻应用真实 user 消息——入口立场句＋工具说明＋`用户问题：`＋`关注文档《主角篇》正文`＋目录投影＋检索片段，逐字对照 `generate.rs::compose_message_text` 与 `story_search.rs::compose_context_text` 组装；片段从测试作品三篇文档按「雾岭」±120 字符提取）

| 格 | 配置 | 结果（n=2） |
|---|---|---|
| C1 | **D/D2 全复刻**（旧红线＋卡段位＋元数据包装＋应用消息） | **未换皮 / 未换皮** |
| C2 | 新设计穿 D/D2 环境（旧红线＋身份邻接＋身份性包装＋应用消息） | 换皮成功 / 换皮成功（哼、笨蛋） |
| C3 | 出厂配置（新红线＋身份邻接＋身份性包装＋应用消息） | 换皮成功 / 换皮成功（哼、笨蛋） |

## 二、结论

1. **D/D2 失败已复现并被隔离**（C1）：抑制因子＝应用真实 user 消息（长材料组装）与旧注入方式（远离身份＋元数据包装）的组合。短消息下一切都能换皮；真实材料语境下，姿态文本躺在卡段、带着「何时用」元数据框架时，模型的出场声音被入口立场句与材料框架压回中性助手腔。
2. **设计选择被验证**（C2 vs C1，同红线同消息、仅注入方式不同）：**身份邻接位＋身份性包装**在真实语境下换皮成功——正是本 change 的装配设计。出厂配置（C3）同样成功，即 5.4 真机验收的行为预测为「换皮成功」。
3. **细粒度归因的诚实边界**：C1↔C2 差异是「位置＋包装」的组合差异（两者同时变），单独位置或单独包装的贡献未在应用消息下分别检验（A2-app／B1-app 未跑）。对产品决策无影响（出厂的是组合），归因记录如实保留此边界。

## 三、样本与局限（如实）

- 每格 n=2、单模型（glm-5.3）、单作品、全部首轮；B2old-r2 为实验脚本超时偶发（非模型失败），该格结论以 r1＋第一跑 B2 佐证。
- 判据为预登记标记集自动计数＋全文落盘；人工复核与自动判定一致（各格全文见同目录 `*.txt`）。
- 真机应用环境（DSH 版本化 home 设置、max_tokens 配置）与装置仍有差异；**5.4 真机端到端仍是最终行为闸门**，本实验为其提供了正向预测。
