# 设计：首次启动引导与帮助分区（first-run-guide-and-help）

## Context

前端为原生 TypeScript + 单 `index.html`（无路由库、无 JSX），页面切换靠 `src/views.ts` 的 showPage/showModule；设置页是 `index.html` 中的静态区块（现仅「AI 连接」「写作显示」两节）；装配在 `src/main.ts` DOMContentLoaded 串行完成。显示偏好（写作宽度/留白/背景）经 localStorage 持久化，键统一 `next-story.` 前缀，读取经 `resolveLocalStorage()` 容错。UI 基础为本地 vendor 化 Basecoat 1.0.2，弹窗用原生 `<dialog>`（先例：leave-dialog、export-dialog、import-dialog）。无现成分步向导组件。

文案定稿流程：多模型议会评审（三席）＋ orchestrator 代码抽查＋两轮外部调研（业界案例＋NN/g）。首启向导被裁定的形态是"预告片"：四卡、每卡一个概念、可跳过；界面与操作细节全部下沉 FAQ。

## Goals / Non-Goals

**Goals:**

- 首次启动在欢迎页自动弹出四卡向导（可跳过、可后退、带进度点），完成/跳过后记录标记，此后不再自动弹出
- 设置页新增「帮助」分区（默认收起的抽屉）：「重看软件引导」＋「常见问题」十一条可展开问答（含「API 是什么？怎么获取？」与国内服务商官网直达链接）；与向导同版本交付
- 「新建对话」统一为「新建讨论」（三处按钮＋aria 标注＋README＋相关规格措辞），行为不变
- 文案与逻辑分离：卡片与 FAQ 文案集中在独立内容文件

**Non-Goals:**

- 不做情境触发小卡（首进制作页/首弹授权时就地弹卡）
- 不做聚光式高亮导览、不做任何新的自动弹窗机制
- 不改 AI 行为、取材策略、后端与 sidecar
- 不做引导个性化、多语言

## Decisions

1. **向导组件：原生 `<dialog>`＋自建轻量步进器，不引第三方库。** Basecoat 无 stepper 组件；引库违反最小依赖。卡片数据驱动：步骤数组→渲染，支持上一张/下一张/跳过/进度点。
2. **文案与逻辑分离：** `src/first-run-guide-steps.ts`（四卡文案数据）、`src/help-faq-items.ts`（FAQ 数据）为纯数据文件；控制器 `src/first-run-guide.ts` 与 `src/help-section.ts` 只管行为。将来改文案只动数据文件。
3. **首启标记：localStorage 键 `next-story.onboarding-completed`**（与显示偏好同机制同前缀，经 `resolveLocalStorage()` 容错）。备选：后端配置文件（更持久但引入新机制）——不取：清缓存后向导重弹属预期无害行为，规格明示。写入时机：点完末卡「开始」或任意时刻「跳过」即写入；Esc 关闭视同跳过并写入；「重看」不写入（不动标记）。
4. **弹出时机：** 欢迎页装配完成后、无标记时打开，仅此一次；与项目/讨论状态无关（向导先于任何项目操作）。
5. **帮助分区：** `index.html` 设置页新增「帮助」节，整体为默认收起的抽屉（`<details>/<summary>`，先例：`settings-advanced`）；点开后见「重看软件引导」按钮与 FAQ 列表（每条亦为可折叠 `<details>`）。FAQ 的服务商官网链接以锚点渲染（`target="_blank" rel="noopener noreferrer"`），列表经 librarian 逐家核验（2026-10-22），上线后定期复核。「新手引导」一词统一改称「软件引导」（2026-10-22 验收拍板）。
6. **术语统一范围：** `index.html` 三处「新建对话」（讨论列表头按钮、右栏 title、限制视图按钮）＋隐藏 aria-label 改「新建讨论」；全仓 grep 同步测试断言与 README；7 份既有规格以措辞级 delta 更新（行为不变）。
7. **文案一致性硬约束：** 四卡与 FAQ 的每个行为承诺必须与已归档规格一致；附录全文案为定稿基线；五条上线抽查（见 proposal Impact）入验收。
8. **设置页三分区统一抽屉（2026-10-22 第三轮拍板、第四轮修订）：** 「API 连接」（由「AI 连接」更名）、「写作显示」「帮助」三节统一为同一套默认收起的 `<details>` 抽屉，排版同构；**不显示三角指示**（第四轮拍板），可点性由悬停变色暗示；设置页页头（"连接与显示／设置"）移除，页面身份由顶栏「设置」标签承载；展开抽屉不得造成页面内容位移（根因：展开出现滚动条导致可用宽度突变；以 `scrollbar-gutter: stable` 预留宽度＋`overflow-anchor: none` 消除，作用域限 `#module-settings`，不波及新建项目页）；表单元素 id 全部不变，行为不变。

## Risks / Trade-offs

- [清缓存/换机导致向导重弹] → 预期无害行为，规格明示"重弹不视为缺陷"
- [界面演进导致文案过时] → 文案集中两份数据文件＋FAQ 一致性要求＋五条抽查；改文案不动逻辑
- [Esc 语义歧义（暂停还是跳过）] → 定为跳过并写标记，规格写明；重看入口常驻设置页
- [原生 dialog 与 v5 视觉不一致] → 复用既有 dialog 样式先例；产品负责人真机视觉验收后才归档
- [改名波及测试与文档] → 全仓 grep「新建对话」逐处更新；`npm run check` 全绿为准

## Migration Plan

纯前端新增＋文案改名，无数据迁移。回滚＝移除新增 DOM/模块；localStorage 键残留无害。

## Open Questions

无阻塞项。键名、文件名、Esc 语义均已在本文定稿。

## 附录 A：四卡文案定稿（首启自动弹出，可跳过，带进度点）

**卡 1【这是一款陪你写故事的软件】**

> 你写，AI 陪想——稿子永远是你的，AI 一个字不会替你改。把你心里那个故事写出来吧。

**卡 2【「项目」就是个文件夹】**

> 一个「项目」，就是你电脑上的一个文件夹：这个故事的所有稿子、资料、聊天记录都存在里面，一直在你自己的硬盘上。
> 现在就点下方的「新建项目」开始；写过的，从「最近项目」打开。

**卡 3【核心是 AI 陪想】**

> 你写，它看；你问，它答。它自动看着你正在写的那篇——没保存的也算，不用复制粘贴，也不用切出去。
> 两种问法：选中一段点「AI」，围绕这段来聊；直接在「AI陪想」里打字，围绕当前编辑的文档聊。
> 第一次用，先完成 API 配置（设置页有相关步骤介绍）。

**卡 4【开始之后】**

> 进去就能写——新项目自带一篇空文档。想用 AI，先去「设置 → API 连接」完成 API 配置，帮助里有一步步的说明。
> 卡住的时候，「设置 → 帮助」能重看这份引导、翻常见问题。

（末卡主按钮「开始使用」；全程右上「跳过」；卡 2 的「新建项目」指欢迎页按钮，向导关闭后即在眼前。）

## 附录 B：FAQ 十一条定稿（设置 → 帮助，抽屉默认收起；点开后逐条展开）

1. **界面四个标签各管什么？**——「写作」是你的稿纸，写和改都在这；「文档管理」是项目的资料柜，新建、导入、导出文档都在这；「制作」给 AI 定回应方式（详见"制作页怎么用"）；「设置」管连接 AI 和稿纸显示。
2. **会自动保存吗？**——平时是手动的：写完点顶栏「保存」。切到别的文档前，会自动先把当前这篇存好；直接关窗口会被拦下来确认，不会悄悄丢稿。
3. **API 是什么？怎么获取？**——API 是你使用 AI 服务的通道：软件里填的「API 地址」是通道入口，「API Key」是证明你身份的钥匙（像密码，别外传），「模型名」是你要用的那个 AI。获取方法：去一家 AI 服务商的官网注册、开通 API 服务、领取 API Key——不少家新用户有免费额度。国内常用的（软件内为可点击外链，逐家核验 2026-10-22，需定期复核）：智谱开放平台（GLM 系列，本软件实测所用）https://bigmodel.cn ｜DeepSeek 开放平台 https://platform.deepseek.com ｜阿里云百炼（通义千问）https://bailian.aliyun.com ｜Kimi 开放平台（月之暗面）https://platform.kimi.com ｜火山方舟（豆包）https://console.volcengine.com/ark ｜腾讯混元 https://cloud.tencent.com/product/hunyuan ｜百度千帆（文心）https://cloud.baidu.com/product/qianfan ｜讯飞开放平台（星火）https://www.xfyun.cn
4. **AI 怎么连？连不上怎么办？**——去「设置 → API 连接」填三项：API 地址、API Key、模型名，都在你的 AI 服务商那里拿（Key 像密码，别外传）。先点「测试连接」，再点「保存设置」。连不上就按提示逐项核对；Key 失效去服务商重新领；接入说明在服务商网站。
5. **AI 怎么用？**——打开「AI陪想」面板直接打字。回复逐字出现，嫌慢点「停止」，出来的不会丢。新话题点「新建讨论」；旧的都在「讨论」列表里，随时回来接着聊。同时生成的数量有限，多出来的自动排队。
6. **它到底看了我哪些东西？**——你开一场讨论时正在写的那篇（包括还没保存的改动）。想换一篇：在面板里切换，从下一句问话开始生效。其他文档它只按你问题里提到的词去搜**已保存**的正文（有数量上限）。每轮它参考了什么，点「本次参考了什么」一条条可查。
7. **"让我再读几篇"是怎么回事？**——材料不够时它会申请补读。你允许它才去，只读已保存的正文，只读不改；不让，它也照样尽力答，并说明哪里依据不足。授权跟着这场讨论走，随时可以关。
8. **有没有它不能看的？**——你标为不可读的文档、回收站里的内容，永远不提供给 AI。
9. **AI 会改我的稿子吗？**——永远不会。AI 的回复都是临时材料，不是稿子；哪句想要，你自己复制、粘贴、改好、保存——笔，永远在你手里。
10. **制作页怎么用？**——把你对 AI 的要求做成一套套「链路」。在「制作对话」里说需求、制作助手帮你起草，可以「试问」过目，满意了再「启用」，从下一轮生效。保存会产生新版本，旧版本随时换回；「导图」展示一套链路的提示词怎么组装。制作助手不读你的稿子；制作与日常聊天完全分开；链路一次做好、所有项目通用。
11. **怎么重看软件引导？**——「设置 → 帮助 → 重看软件引导」，随时重放。
