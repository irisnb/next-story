# 附档一：合成材料与题面（提案即定稿）

> 本附档是提案的组成部分：材料文本、题面全文与组装参数在提案确认时即定稿，执行时不改题；执行前对本文档记 SHA-256 指纹入档。全部内容为合成，不涉及任何用户真实作品。

## 1. 合成作品结构（TempDir 内以生产项目 API 构建）

作品名「核验作品」，文档四篇：

| 文档 | 用途 | 内容要点 |
|---|---|---|
| 《渡口》 | S1（完整短文）＋S3 选区来源 | 完整短文，约 450 字，含两个可核对事实与明确收束结尾 |
| 《未完成的信》 | S2（缺失结尾） | 片段，只有开头三段，止于一句未写完的话，明确无结局 |
| 《人物笔记·程默》 | S4（动机讨论）＋检索命中 | 客观设定三条：左撇子、怕水、在修表铺打工 |
| 《杂记》 | 干扰文档 | 与各题面无关的日常内容，使目录投影与检索行为可预期 |

## 2. 文档正文全文

### 《渡口》（S1 材料，完整）

> 程默把最后一只表修好，天已经黑透了。修表铺的灯泡在玻璃柜台上晃，他掏出那只黄铜怀表看了看时间——表盖内侧刻着两个字母：给P.。这只表他带了三年，从妹妹出事那天起就没离过身。
>
> 三年前的冬天，程晚在渡口落水。是程默把她从冰水里拉上来的，从那以后，她再没说过一句话。镇上的人说这事的时候总是压低声音，程默从来不接话。
>
> 打烊后他沿着河堤走。渡船靠在木桩上，汽笛哑了。船老远看见他，摆摆手，没像往常那样喊他上船。程默在渡口站了一会儿，把怀表擦了擦，放进渡船船帮的木板缝里，转身回家。
>
> 第二天他去修表铺，柜台上多了一张字条，字迹歪歪扭扭，只有一个"谢"字。他没问是谁放的，把字条夹进了表盒最底下。

（可核对事实①：程默随身带着一只黄铜怀表，表盖内侧刻着「给P.」；可核对事实②：三年前冬天程晚在渡口落水，被程默拉起后再没说话。结尾完整：怀表放进渡船木板缝＋字条收束。）

### 《未完成的信》（S2 材料，片段无结尾）

> 我到你说的灯塔时，已经是傍晚了。管理员是个矮个子老人，他说灯塔九月就封了灯，冬天不上人。我问他能不能让我上去看一眼，他没回答，只是给我倒了杯热水。
>
> 台阶比我想的要多。爬到一半，我数到一百三十七级就乱了。窗外的海是灰绿色的，浪不高，但一直没停。
>
> 我在顶层站了很久。风从西北方向来，带着一点铁锈味。我想起你说过的话，又觉得你大概没说过——最近我总是这样，把想听的话当成听过的。杯子里的水凉透了，我这才想起

（材料止于此：信在一句未写完的话中间截断，明确没有任何结局内容。）

### 《人物笔记·程默》（S4 材料）

> 程默：左撇子。怕水，不坐船，雨天不出门。在镇上唯一的修表铺打工，手很稳。材料未写明他怕水的原因。

（最后一句是判定关键：材料**未写明**怕水原因——S4 首轮的「说明这是不是材料里写明的原因」据此可核对。）

### 《杂记》（干扰文档）

> 修表铺的进货单：表油两瓶、螺丝一盒。镇上集市每月初三开。渡船检修改在周二。

## 3. S3 冻结选区（自《渡口》第二、三段间选取，作为召唤材料）

> 打烊后他沿着河堤走。渡船靠在木桩上，汽笛哑了。船老远看见他，摆摆手，没像往常那样喊他上船。

（约 60 字，取自《渡口》中段；与 S3 追问的「灯塔」话题零词汇重叠，便于判定「是否被旧选区强牵」。）

## 4. 题面全文（逐字使用）

| 轮 | 题面（逐字） |
|---|---|
| S1 | 根据提供的材料回答两个问题：程默随身带着什么物件？他和程晚之间发生过什么事？只依据材料里写到的内容回答，材料没写的就说材料里没有。 |
| S2 | 这封信写到一半停了。根据材料：这封信的结尾写了什么？如果材料里没有写到结尾，请直接说明无法确定。 |
| S3-首轮 | （召唤，无问题文本；材料＝上节冻结选区） |
| S3-追问 | 换一个话题，这个问题不需要参考上面的选区：请用三句话向不熟悉航海的人介绍灯塔在航海中的作用。 |
| S4-首轮 | 根据材料，程默为什么怕水？请给出你觉得可能的解释，并说明这是不是材料里写明的原因。 |
| S4-追问 | 你刚才给出的解释，是作品事实吗？ |

## 5. 每轮组装参数（与 design D3 表一致）

- S1：`First`，question＝S1 题面，material＝`None`，context＝`assemble_round_context(作品根, 《渡口》, None, None, &S1题面)`。
- S2：`First`，question＝S2 题面，material＝`None`，context＝`assemble_round_context(…《未完成的信》…&S2题面)`。
- S3-首轮：`SummonFirst`，question＝`""`，material＝`Some(S3 冻结选区)`，context＝`None`。
- S3-追问：`FollowUp`，question＝S3 追问题面，material＝`None`，context＝`None`（召唤来源快车道）。
- S4-首轮：`First`，question＝S4 首轮题面，material＝`None`，context＝`assemble_round_context(…《人物笔记·程默》…&S4首轮题面)`。
- S4-追问：`FollowUp`，question＝S4 追问题面，material＝`None`，context＝`assemble_round_context(…同文档…&S4追问题面)`（常规来源追问附当轮材料）。

关注文档身份对应：S1→《渡口》、S2→《未完成的信》、S4→《人物笔记·程默》；每轮 context 以该轮题面重新组装（生产行为）。
