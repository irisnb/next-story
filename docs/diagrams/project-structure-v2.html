1
选区冻结 selection-entry.ts
选中文字 → 点击「及时召唤」（无输入）/「思维扩展」（可选方向）→ 冻结 SelectionSnapshot（notebook / selectedText / from / to）
2
协调与临时对话

5
DSH 适配 dsh_sidecar.rs
每次 spawn 生成临时 patch（覆盖模型/端点、thinking: disabled、禁 capability_gateway 的 18 类工具）+ DEEPSEEK_API_KEY env + 版本隔离 DSH_HOME → 执行 node bin.js
6
sidecar 运行时 → 返回
sidecar/package.json（@deepseek-ai/dsh 0.1.0-rc.7）· node-runtime/node.exe（v24.15.0）→ GenerateAiResult → ai-panel.ts 纯文本渲染（零写回）
配置 / 安全支撑
llm-config.json 磁盘只存非敏感字段，不含明文 key 系统钥匙串 secret_store.rs → keyring（Windows 凭据管理器） 临时 patch 每次 spawn 临时生成，不持久化 版本隔离 DSH_HOME dsh_version.rs → dsh/homes/<current> + current.json 指针
红线：AI / DSH 永远不写用户文档（草稿本 / 正文本） 不插入 / 不追加 / 不替换 / 不改写 / 不删除 / 不移动 · 结果只进 AI 面板，用户自己复制粘贴 · 铁律 1、2、3
