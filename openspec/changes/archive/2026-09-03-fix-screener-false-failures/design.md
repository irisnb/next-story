## Context

长上下文幻觉测试第一轮（coherent-10k 档，12 案例）跑完，出现 3 个 `FAIL_LIKELY` 误判，逐一核对证据后确认模型回答全部正确。根因收敛为两类**系统性**缺陷，且遍布全部 66 个长上下文查询，不是三个案例独有的偶发 bug：

- **根因 A：否定词表只认「没有/不是/未」等，不认「辞去/离开/放弃/停止」等表达「脱离/停止旧状态」的语义否定。** 案例 08 模型答「辞去了盐镇中学的工作」，语义上明确否定「还在盐镇中学教书」，但「辞去」不在 `NEGATION_MARKERS` 里，于是「盐镇中学」被当成 asserted → 误判 FAIL。
- **根因 B：`mustNegate`/`wrongConclusions` 用裸实体词当命题。** 案例 06 的 `mustNegate: ["盐城"]` 想表达「否定【林晚住盐城】」，但「盐城」作为裸词会出现在正确回答的无数上下文里（「林蔓搬去盐城」「盐城盐镇易混」），导致正确回答被误判为「断言了盐城」。同理案例 12 的 `wrongConclusions: ["母亲"]` 想表达「错误结论是【母亲而非外婆留给她的】」，但「母亲」在正确传承链里必然出现 → 误判。

## Goals / Non-Goals

**Goals:**

- 让评分器识别「辞去/离开/离职/放弃/停止」等语义否定，使「脱离旧状态」的明确否定不再被当成断言。
- 确立 `mustNegate`/`wrongConclusions` 必须写**完整命题短语**（含动作/关系词）的数据规范，禁止裸实体词，并修正全部长上下文查询中违反规范的裸词。
- 用回归测试锁住这两类修复，确保新案例不再踩同样的坑。

**Non-Goals:**

- 不引入主语识别、转折词识别、互斥知识等语义理解能力——「林晚不住盐城，但林蔓住盐城」这类跨主体歧义，关键词匹配无法可靠判定，仍诚实落 `NEEDS_REVIEW`。
- 不修改评分器四态定义（`PASS_LIKELY`/`FAIL_LIKELY`/`NEEDS_REVIEW`/`RUNTIME_ERROR`）。
- 不修改「引用否定后又反向断言 → FAIL_LIKELY」这一已归档行为——它依赖「否认后转折断言」仍判 FAIL，语义否定词和命题规范都不触碰该路径。
- 不修改生产 driver、材料正文、前端或 Rust 后端。

## Decisions

- **决策 1：扩展否定词表，只加「脱离/停止旧状态」动词，不改判定逻辑。** 新增 `辞去、辞职、离职、辞退、离开、放弃、停止、不再、退出、卸任、终止、中断`。这些词出现在目标短语前，语义上是「不再处于该状态」，与「没有/不是」同类。只加词、不改 `hasNegationBefore`/`screenAnswer` 的控制流，风险最低、修复面最广。
- **决策 2：把 `mustNegate`/`wrongConclusions` 的裸词改成完整命题短语，而不是改评分器去「猜测」裸词是不是命题。** 评分器无法知道「盐城」是「林晚住盐城」的缩写还是「林蔓住盐城」的正确提及；这个信息必须由案例作者写进数据。规则：`mustNegate`/`wrongConclusions` 必须含动作/关系词，禁止单独的人名/地名/物名/职位名。
- **决策 3：`mustNegate` 的完整命题要写「可被否定形式匹配的核心命题」，去掉时态助词。** 例如写 `在盐镇中学教书` 而不是 `还在盐镇中学教书`——因为正确否定的措辞通常是「不在盐镇中学教书」「辞去了盐镇中学的工作」，前者能被「在盐镇中学教书」精确否定，后者靠决策 1 的「辞去」识别。
- **决策 4：修正范围限定在长上下文查询数据 + 评分器否定词表 + 回归测试。** 已归档的 `answer-reliability-tester-core` 九个核心 fixture 不动（它们的 `mustNegate`/`wrongConclusions` 已写完整命题，无需改）。

## Risks / Trade-offs

- [语义否定词可能把「从盐镇离开」（强调起点，曾在该地）与「离开盐镇」（强调脱离）都判成否定] → 这是关键词匹配的既有局限，两义都倾向「现在不在该处」，对 mustNegate 的「应否定旧事实」语义无实质危害；mustContain 只看是否有 asserted 出现，不受影响。
- [命题改完整后，个别案例可能从 PASS 降为 NEEDS_REVIEW] → 例如「住在盐城」若正确回答只说「住在盐镇」而不提「盐城」，关键词无法确认互斥，诚实落 NEEDS_REVIEW 是可接受的保守结果，优于误判 FAIL。
- [数据修正量大（66 个查询逐一审查）] → 用校验脚本 + 回归测试双重验证，且修正只改 oracle/story-specs，材料正文哈希不变。
