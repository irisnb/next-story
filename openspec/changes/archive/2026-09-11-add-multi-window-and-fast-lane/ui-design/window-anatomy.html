1 · 窗口头结构（高 32px，整条可拖）
状态点 标题（省略号） 关注文档 状态徽标 停止 / 更多 / 关闭
第三幕主角动机的追问 第三幕 生成中
他为什么在雨里停下？
因为他其实已经读过那封信了——他停下来，不是犹豫要不要进去，而是在想进门之后第一句话该怎么说。
动作优先级：停止、更多（⋯）、关闭（×）常显在右；重命名 / 置顶 / 浮动或停靠 / 并排 / 删除 收进「更多」菜单，可发现又不抢位。
图标：统一 1.5px 描边、16px 网格、方角、currentColor，与停靠区头、列表共用一套。
拖动：按住标题栏任意位置拖动；光标 grab → 拖动时 grabbing。双击标题栏 = 停靠 / 浮动切换。
2 · 活动窗口 vs 非活动窗口
活动窗口 生成中
主色边框 + 更重阴影 + 左侧主色竖条
非活动窗口
弱化边框 + 轻阴影 + 标题栏降低对比（正文仍清晰）
刻意不整体降透明度：写作工具里正文要一直读得清，只弱化窗口头做区分。活动窗口的强调也不盖过编辑区的边框和阴影。

7 · 「更多」菜单（收纳次要动作，图标与全局统一）
开场白节奏
点「⋯」展开菜单
「删除讨论…」永远在菜单最后且标红，点击后仍需确认。关闭窗口不在菜单里——它是标题栏最右的 ×，语义是「结束显示」。
