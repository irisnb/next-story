## 2. 导图视图（总览）

- [x] 2.1 `making-view-model.ts` 新增导图视图构建器：三区数据（「自定义要求」（含「要求类插槽」组＋紧凑卡行＋ghost 加卡）／「固定底座」／「每轮动态」）、输出象征块、三态标题、箭头连线数据；删除旧「简版列表」构建器
- [x] 2.2 `making-module.ts` 渲染导图：三区同构分区与卡行、ghost「＋添加要求卡」；SVG 箭头仅出现在「分区→组装」「组装→输出」连线（`marker-end`），卡片节点不生成任何连线（DOM 结构保证）
- [x] 2.3 图区容器独立、组装／输出块以图区为基准垂直居中；底部阅读说明条（免责句＋「箭头只表示流向组装，不表示卡片执行顺序」＋「启用对象是整个链路版本」）贴底且在图区容器之外（不参与居中计算）
- [x] 2.4 「自定义要求」区定高＋`overflow-y` 滚动；ghost 加卡入口位于滚动内容尾部
- [x] 2.5 三套可改性外观（可改区 hover 可点态／只读区平面弱样式无 hover／「每轮动态」自动标识）；输出块不可点形态（无 hover 可点态、无任何详情入口）

## 3. 统一详情呈现

- [x] 3.1 单一详情控制器＋`DetailModel`：三类来源（卡片／固定底座／每轮动态）产出同一模型，仅内容与可操作性不同
- [x] 3.2 快捷小窗：统一挂载位（水平卡区右侧邻接、垂直以图区为基准居中）、统一尺寸、可关闭；不随所点对象及其位置变化
- [x] 3.3 全页详情：占满导图视图、明确返回入口；卡片五项（身份／何时用／怎么做完整正文／本版变化／试问记录，无试问明示「尚无试问记录」）＋底部「修改／删除／添加」统一转入制作对话；固定底座与每轮动态详情只读、无任何操作或配置控件
- [x] 3.4 卡片无启用开关：启用操作仅出现在链路版本层（沿用既有启用流与确认措辞）
