# 能力：主窗口尺寸边界（main-window-size-bounds）

## ADDED Requirements

### Requirement: 主窗口最小尺寸
系统 SHALL 将主窗口的最小尺寸限制为 1024×670 逻辑像素（宽×高）。用户不得能通过拖拽边缘、输入尺寸或任何应用内操作把主窗口缩小到该尺寸以下。

#### Scenario: 拖拽不能小于下限
- **WHEN** 用户拖动窗口边缘或角落，尝试把宽度缩到 1024 逻辑像素以下或高度缩到 670 逻辑像素以下
- **THEN** 窗口分别在宽到达 1024、高到达 670 时停止缩小

#### Scenario: 默认尺寸等于最小尺寸
- **WHEN** 应用启动并创建主窗口
- **THEN** 主窗口以 1024×670 逻辑像素居中打开（默认尺寸与最小尺寸一致，窗口只能放大）

### Requirement: 最小尺寸按逻辑像素定义
系统 SHALL 以逻辑像素定义主窗口的最小尺寸，使其在高 DPI 显示缩放下自动换算为对应物理像素，窗口内布局比例不随缩放漂移。

#### Scenario: 高 DPI 缩放下布局保证不变
- **WHEN** 系统显示缩放设为 125% 或 150%
- **THEN** 主窗口最小尺寸对应放大后的物理像素，最小宽度下「AI 停靠面板与正文并排」的布局仍完整成立

### Requirement: 常规窗口操作不受影响
设定最小尺寸后，系统 SHALL 保持最大化、还原与启动居中等既有窗口行为不变。

#### Scenario: 最大化与还原正常
- **WHEN** 用户最大化主窗口后再还原
- **THEN** 窗口恢复到最大化之前的尺寸（不低于最小尺寸），最大化与还原功能无异常

#### Scenario: 1366×768 屏幕完整容纳
- **WHEN** 应用在物理分辨率 1366×768、100% 缩放的屏幕上以默认尺寸打开
- **THEN** 主窗口完整落入系统可用工作区，不被任务栏遮挡或超出屏幕
