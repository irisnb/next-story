## MODIFIED Requirements

### Requirement: 粘贴图片不得进入作品文档
系统 MUST 忽略外部内容中的图片且不得插入图片节点或 `[图片]` 占位。图文混合内容中存在可可靠提取的文字时，系统 SHALL 插入文字并显示中文提示说明图片未被加入；纯图片内容 MUST 不改变文档并显示中文提示。

#### Scenario: 粘贴图文混合内容
- **WHEN** 用户粘贴包含图片和可提取文字的内容
- **THEN** 编辑器只插入可提取文字及支持结构
- **AND** 系统显示图片未被加入的中文提示

#### Scenario: 粘贴纯图片
- **WHEN** 用户粘贴的内容只包含图片
- **THEN** 当前文档内容和历史不发生变化
- **AND** 系统显示无法将图片加入文档的中文提示

### Requirement: 无法保证文字完整时拒绝整次粘贴
HTML 与 `text/plain` 同时存在时，系统 MUST 按以下唯一比较规则验证完整性：两侧都把 CRLF 和 CR 转为 LF、把 NBSP 转为普通空格、删除每行末尾的空格和 Tab；随后两侧各自独立地从最终字符串末尾删除至多一个 LF（若末尾存在 LF 则删一个，不存在则不删；不依赖该 LF 的来源）。HTML 侧每个归一化块投影为一行且不生成列表符号；`text/plain` 中与 HTML 列表项对应的行只可额外去掉一个前导 `• `、`- `、`* ` 或十进制整数加 `. ` 的列表标记。完成上述处理后的行数组 MUST 完全相同，包括空行、Tab、行顺序和行数，否则系统 MUST 拒绝整次粘贴。只有 HTML 而没有 `text/plain` 时，系统 MUST 在遇到含可见文字的嵌入结构且无法按已定义映射处理时拒绝整次粘贴。任何归一化结果未通过 schema 校验时也 MUST 拒绝，保持当前文档和历史不变，并显示中文原因。系统 MUST NOT 插入已知残缺结果。

#### Scenario: HTML 与纯文本不一致
- **WHEN** 同一次粘贴的归一化 HTML 投影缺少 `text/plain` 中的非空可见文字或改变其顺序或段落边界
- **THEN** 系统不插入任何本次粘贴内容
- **AND** 系统显示粘贴失败原因的中文提示

#### Scenario: 只有 HTML 且包含未知嵌入内容
- **WHEN** 剪贴板没有 `text/plain` 且 HTML 包含无法按已定义映射处理并带有可见文字的嵌入内容
- **THEN** 系统拒绝整次粘贴
- **AND** 当前文档内容和历史保持不变

#### Scenario: 归一化结果不符合编辑器 schema
- **WHEN** 粘贴内容归一化后的文档片段未通过当前 schema 校验
- **THEN** 系统拒绝整次粘贴并保持当前文档不变
- **AND** 系统不把残缺片段加入撤销历史

## ADDED Requirements

### Requirement: 文档内复制和剪切保持本轮支持的内容
系统 SHALL 让文档内复制提供与选区对应的纯文本和受控 HTML 表示，并 SHALL 让粘贴回本应用时保留本轮支持的结构与标记。剪切 MUST 只删除当前文档实际选中的内容，并作为可撤销操作处理。

#### Scenario: 复制格式内容到另一文档
- **WHEN** 用户复制包含标题、粗体和列表的选区并粘贴到另一文档
- **THEN** 目标文档保留对应可见文字和本轮支持的格式
- **AND** 源文档不发生变化

#### Scenario: 剪切格式内容
- **WHEN** 用户剪切当前文档的一个格式化选区
- **THEN** 剪贴板获得该选区的纯文本和受控格式表示
- **AND** 当前文档只删除实际选中的内容
