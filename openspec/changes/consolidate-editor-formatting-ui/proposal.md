## Why

第三轮已经实现了全部文字与段落格式能力（字符格式、段落格式、嵌套列表、查找替换、链接、右键菜单、粘贴选项），但这些控件的入口散落在顶部横排工具栏、右侧抽屉、右键菜单和快捷键四处。用户实际使用中发现「东一块西一块」：想排版时记不住某个功能在哪、找起来费劲。需要把格式控件整合成一个清晰的「左侧工具栏 + 左侧格式抽屉」分层结构，让编辑栏按需隐藏、给正文更多呼吸感，降低中文剧本长文写作的使用成本。

## What Changes

- 把顶部横排工具栏改为**左侧竖排工具栏**（PS 风格），只保留高频项：粗体、斜体、下划线、删除线、无序/有序列表、段落样式、撤销/重做、查找入口、格式抽屉开关。
- 把格式抽屉移到**左侧**，并按「字符格式 / 段落格式」两节**可折叠**，作为所有格式控件的**分类目录**（全量格式都在这里，一处找全）。
- 工具栏与抽屉**自动隐藏**：鼠标移出抽屉即收起；整条左栏在不使用时缓缓隐去，鼠标移到窗口左边缘再唤起。
- 查找栏增加**可见入口按钮**（工具栏「查找」），不再只能靠 `Ctrl+F` / `Ctrl+H` 快捷键。
- 右键菜单**精简**为剪切、复制、粘贴、粘贴为纯文本 + 链接命令，移除格式命令，为后续用途留白。
- 新增**编辑器「留白」调节**（正文四周的显示留白），作为界面显示偏好，不写入作品文档、不影响 AI 输入。
- 不做选区气泡（AI 选区入口已经占据选中文字附近的位置）。
- 纸张页边距、分页、纸张尺寸与 DOCX 导出归入未来独立的「导出」change，本轮不做。

## Capabilities

### New Capabilities

- `editor-margin-preference`: 编辑器正文四周留白的调节与持久化，作为界面显示偏好，不进入作品文档。

### Modified Capabilities

- `basic-rich-text-editing`: 工具栏从「本子标签下方横排」改为「左侧竖排工具栏 + 左侧格式抽屉（字符/段落分节）」，并增加自动隐藏行为。
- `editor-context-menu`: 移除格式命令，精简为剪切/复制/粘贴/粘贴为纯文本 + 链接命令。
- `find-replace`: 查找栏增加可见入口按钮，`Ctrl+F`/`Ctrl+H` 仍可用。

## Impact

- 前端：`index.html`（左侧工具栏与抽屉结构、查找栏入口）、`src/styles.css`（左侧竖排布局、抽屉分节、自动隐藏过渡动画）、`src/dom.ts`、`src/editor.ts`（工具栏/抽屉/查找/右键的 wiring 与自动隐藏逻辑、留白偏好读写）及相关测试。
- 偏好持久化：编辑器留白作为应用级显示偏好保存，与作品文档、LLM 配置分开，不写入 `草稿本.json` / `正文本.json`。
- 不涉及：文档格式与校验（`structured-notebook-storage` 不变）、Rust 后端、AI 写稿边界、两个本子的内容事实源。
- 文档：本轮不改变「纸张页边距/分页/DOCX 导出」的既定边界，三者作为后续「导出」change 的方向记录在案。
