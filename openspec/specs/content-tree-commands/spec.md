## Requirements
### Requirement: 前端可读取整棵内容树结构
系统 SHALL 提供一个读取整棵内容树的命令，返回作品内容树的完整结构，包括根级子节点顺序、每个节点的 ID / 名称 / 类型（文件夹或文档）/ 子节点顺序，以及回收站中被删除的子树。返回的结构 MUST 通过后端内容树校验，MUST NOT 返回未通过校验的树结构。

#### Scenario: 读取合法内容树
- **WHEN** 前端对已打开的作品请求读取内容树
- **AND** 作品内容树结构合法且一致
- **THEN** 系统返回整棵树的结构（根级子节点顺序、节点 ID / 名称 / 类型 / 子节点顺序、回收站子树）

#### Scenario: 读取非法内容树被拒绝
- **WHEN** 前端请求读取内容树
- **AND** 内容树结构非法（如存在循环、孤儿节点、同级重名）
- **THEN** 系统拒绝并返回中文可读错误
- **AND** 系统不返回未通过校验的树结构

### Requirement: 前端可按文档 ID 读取单篇文档正文
系统 SHALL 提供一个按文档 ID 读取单篇文档正文的命令。文档 ID MUST 是内容树中存在的文档节点；读取的正文 MUST 为合法 Tiptap JSON（格式版本 2），且 MUST 在返回前通过后端校验。ID 不存在或正文非法时，系统 MUST 拒绝并返回中文可读错误。

#### Scenario: 读取存在的文档
- **WHEN** 前端按一个存在于内容树中的文档 ID 请求读取正文
- **AND** 该文档正文文件为合法 Tiptap JSON
- **THEN** 系统返回该文档的正文 JSON 字符串

#### Scenario: 读取不存在的文档 ID
- **WHEN** 前端按一个不存在于内容树中的 ID 请求读取正文
- **THEN** 系统拒绝并返回中文可读错误

#### Scenario: 读取非法正文被拒绝
- **WHEN** 前端按文档 ID 请求读取正文
- **AND** 该文档正文 JSON 损坏、格式版本不支持或 schema 非法
- **THEN** 系统拒绝并返回中文可读错误
- **AND** 系统不把失败内容替换为空白返回

### Requirement: 前端可按文档 ID 保存单篇文档正文
系统 SHALL 提供一个按文档 ID 保存单篇文档正文的命令。文档 ID MUST 是内容树中存在的文档节点；正文 MUST 为合法格式版本 2 文档，且 MUST 在写入前通过字节上限与结构校验。保存 MUST 作为一个完整一致世代提交，失败或中断 MUST NOT 留下部分应用的状态。本命令 MUST NOT 提供任何让 AI 写入用户文档的路径。

#### Scenario: 保存存在的文档
- **WHEN** 前端按文档 ID 提交一篇合法文档正文
- **AND** 该 ID 是内容树中存在的文档节点
- **THEN** 系统把该文档正文写入其正文文件
- **AND** 系统更新作品元信息的 `updated_at`
- **AND** 保存作为一个完整一致世代提交

#### Scenario: 保存不存在的文档 ID 被拒绝
- **WHEN** 前端按一个不存在于内容树中的 ID 提交正文
- **THEN** 系统在写入前拒绝
- **AND** 可见项目文件保持原世代

#### Scenario: 保存非法或超限正文被拒绝
- **WHEN** 前端提交的正文未通过格式版本 2 校验或超过字节上限
- **THEN** 系统在创建事务暂存文件前拒绝
- **AND** 返回中文可读错误
- **AND** 可见项目文件保持原世代

### Requirement: 前端可创建文件夹和文档
系统 SHALL 提供创建文件夹与创建文档两个命令，允许在指定父级（含根级，用空父级表示）下创建新节点。新节点 MUST 分配唯一默认名，与同级冲突时生成不冲突名称；创建文档 MUST 同时生成一篇合法空正文文件。创建 MUST 作为结构变更事务提交。

#### Scenario: 在父级下创建文件夹
- **WHEN** 前端在指定父级（含根级）下请求创建文件夹
- **THEN** 系统创建该文件夹并返回其 ID
- **AND** 文件夹获得唯一默认名

#### Scenario: 在父级下创建文档
- **WHEN** 前端在指定父级（含根级）下请求创建文档
- **THEN** 系统创建该文档并返回其 ID
- **AND** 系统为它生成一篇合法空正文文件

#### Scenario: 在文档下创建被拒绝
- **WHEN** 前端请求在文档节点下创建子节点
- **THEN** 系统拒绝并返回中文可读错误
- **AND** 不产生任何新节点

### Requirement: 前端可重命名节点
系统 SHALL 提供重命名命令，校验新名称非空、不含当前操作系统非法文件名字符、与同一父级内其它节点不重复。校验失败 MUST 拒绝并保持原名称不变。

#### Scenario: 重命名为合法唯一名称
- **WHEN** 前端把节点重命名为非空、合法且与同级不重复的名称
- **THEN** 系统更新该节点名称

#### Scenario: 重命名被拒绝时保持原名
- **WHEN** 前端提交空名称、含非法字符或与同级重复的名称
- **THEN** 系统拒绝并返回中文可读错误
- **AND** 原名称保持不变

### Requirement: 前端可移动节点
系统 SHALL 提供移动命令，把节点（含完整子树）移动到另一父级（含根级）。系统 MUST 禁止把文件夹移动到其自身或任意后代之内（循环检测）。移动后节点及完整子树保持完整。

#### Scenario: 移动文档到另一文件夹
- **WHEN** 前端把文档移动到另一文件夹
- **THEN** 系统更新其父级
- **AND** 文档内容保持不变

#### Scenario: 禁止把文件夹移入自身或后代
- **WHEN** 前端尝试把文件夹移动到其自身或其任意后代之内
- **THEN** 系统拒绝并返回中文可读错误
- **AND** 原结构保持不变

### Requirement: 前端可重排子节点顺序
系统 SHALL 提供排序命令，重排指定父级内子节点的顺序。提交的顺序列表 MUST 完整覆盖该父级所有子节点且不重复，否则系统 MUST 拒绝。

#### Scenario: 重排父级子节点顺序
- **WHEN** 前端提交一个完整覆盖父级所有子节点且不重复的顺序
- **THEN** 系统按该顺序更新父级子节点列表

#### Scenario: 不完整的排序列表被拒绝
- **WHEN** 前端提交的顺序列表缺失子节点或含重复或含未知 ID
- **THEN** 系统拒绝并返回中文可读错误
- **AND** 原顺序保持不变

### Requirement: 前端可删除节点进回收站并恢复
系统 SHALL 提供删除与恢复两个命令。删除 MUST 把节点（含完整子树）移入回收站而非永久删除，正文文件保持原位；恢复 MUST 把回收站中的子树移回原父级，层级、顺序与名称保持删除前状态。恢复不存在的或已被占用的节点 MUST 拒绝。

#### Scenario: 删除节点进回收站
- **WHEN** 前端删除一个节点
- **THEN** 系统把该节点及其完整子树移入回收站
- **AND** 节点不再出现在内容树中
- **AND** 正文文件保持原位不被删除

#### Scenario: 恢复被删除的子树
- **WHEN** 前端从回收站恢复一个被删除的节点
- **THEN** 系统把该子树恢复到原父级
- **AND** 层级、顺序与名称保持删除前状态

#### Scenario: 恢复不存在的节点被拒绝
- **WHEN** 前端请求恢复一个不在回收站中的 ID
- **THEN** 系统拒绝并返回中文可读错误

### Requirement: 内容树命令不得暴露任何 AI 写文档能力
系统 MUST NOT 通过本 capability 提供任何让 AI 写入、插入、追加、替换、删除或移动用户文档的能力。内容树命令只面向前端界面操作，不注册为任何 AI 可调用的写文件工具。

#### Scenario: 内容树命令不是 AI 写文档入口
- **WHEN** 系统提供内容树命令
- **THEN** 这些命令不暴露给 AI 运行时调用
- **AND** AI 输出仍只能留在用户文档之外，由用户亲手复制、编辑并保存
