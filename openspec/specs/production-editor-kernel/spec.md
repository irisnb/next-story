## Requirements
### Requirement: 中文组合输入和常用编辑操作稳定
系统 SHALL 在 Windows Tauri 2 / WebView2 中支持中文输入法组合输入、光标移动、鼠标与键盘选区、复制、剪切、受控粘贴、撤销和重做。组合输入 MUST NOT 丢字、重复、乱序或生成与一次实际编辑不相符的异常历史步骤。

#### Scenario: 微软拼音组合输入
- **WHEN** 用户使用微软拼音完成拼音组合、候选选择和文字上屏
- **THEN** 编辑器只产生用户确认的中文文字
- **AND** 文字不丢失、不重复且顺序正确

#### Scenario: 组合期间删除和切换焦点
- **WHEN** 用户在中文组合输入期间使用退格或把焦点切到 AI 面板后再返回
- **THEN** 编辑器保持确定且可继续写作的文字与光标状态
- **AND** 不产生重复文字或损坏本子内容

#### Scenario: 撤销和重做用户编辑
- **WHEN** 用户通过常见 Windows 快捷键撤销或重做输入、删除、剪切、粘贴或格式命令
- **THEN** 编辑器按实际编辑历史恢复对应结构化文档
- **AND** 一个本子的撤销重做不改变另一个本子

### Requirement: 两个本子的编辑状态和历史互相隔离
系统 SHALL 为草稿本和正文本分别维护结构化文档、光标、选区和撤销重做历史。标签切换 MUST NOT 被记录为内容或格式编辑，也 MUST NOT 让一个本子的文档或历史覆盖另一个本子。

#### Scenario: 切换后恢复本子编辑上下文
- **WHEN** 用户在草稿本编辑并形成光标或选区状态后切换到正文本再返回
- **THEN** 草稿本保留切换前的全部未保存文字和格式
- **AND** 草稿本恢复可继续编辑的自身上下文

#### Scenario: 分别撤销两个本子的编辑
- **WHEN** 用户先后修改草稿本和正文本
- **AND** 用户在各自本子中触发撤销
- **THEN** 每次撤销只作用于当前本子的自身编辑历史

### Requirement: 编辑器实例随作品生命周期释放
系统 MUST 在作品卸载、成功打开另一作品或编辑器控制器销毁时解除两个 Tiptap 实例的事件监听并销毁实例。已销毁的实例 MUST NOT 再改变当前作品的保存状态、选区入口或本子内容。

#### Scenario: 打开另一作品
- **WHEN** 用户成功离开当前作品并打开另一作品
- **THEN** 系统销毁原作品的两个编辑器实例
- **AND** 新作品只显示从新项目文件读取的草稿本和正文本

#### Scenario: 旧实例迟到事件
- **WHEN** 原作品编辑器实例已经销毁
- **AND** 旧实例相关的迟到回调随后发生
- **THEN** 系统忽略该回调
- **AND** 当前作品的保存状态和 AI 入口不受影响

### Requirement: 真实剧本长度下编辑保持可用
系统 SHALL 在 Windows Tauri 2 / WebView2 中以至少 20 万汉字且包含本轮格式组合的本子验证载入、连续输入、格式命令、选区、滚动、撤销重做和保存重开。连续输入延迟 p95 MUST 不高于 50ms，载入后的进程增量内存 MUST 不高于 300MB，并 MUST NOT 出现内容损坏、格式丢失或选区漂移。

#### Scenario: 载入并编辑 20 万字格式化本子
- **WHEN** 用户在 Windows 桌面应用中打开至少包含 20 万汉字和本轮格式组合的本子并连续输入
- **THEN** 连续输入延迟 p95 不高于 50ms
- **AND** 载入后的进程增量内存不高于 300MB
- **AND** 输入、格式命令、选区和滚动期间不发生内容损坏或选区漂移

#### Scenario: 长文档保存重开
- **WHEN** 用户编辑至少 20 万汉字且包含本轮格式组合的本子并手动保存后重新打开作品
- **THEN** 两个本子的文字、段落顺序和支持格式与成功保存时一致

### Requirement: 生产写作区使用 Tiptap 基础富文本内核
系统 SHALL 使用 Tiptap（底层为 ProseMirror）承载草稿本和正文本的生产写作区，并 MUST 将内部文档限制为格式版本 1 支持的正文、一级标题、二级标题、粗体、斜体、无序列表和有序列表结构。系统 MUST NOT 开放或持久化链接、图片、表格、三级及更深标题、字体、字号、颜色、背景、下划线或其它未确认格式。

#### Scenario: 打开已有结构化作品
- **WHEN** 用户打开包含有效 `草稿本.json` 和 `正文本.json` 的作品
- **THEN** 系统用两个文件的完整 Tiptap 文档分别初始化草稿本和正文本编辑器
- **AND** 编辑器显示已保存的文字、段落和支持格式

#### Scenario: 编辑基础富文本
- **WHEN** 用户在任一本子中输入、删除、换行或应用本轮格式
- **THEN** 编辑器显示与用户操作一致的文字和支持格式
- **AND** 系统不因内部文档结构增加用户未输入的可见文字

#### Scenario: 不提供范围外富文本能力
- **WHEN** 用户使用本 change 完成后的编辑器
- **THEN** 编辑器不开放链接、图片、表格或其它范围外格式命令
- **AND** 内部 schema 不接受范围外节点或标记

### Requirement: 结构化文档保持支持的内容和格式
系统 MUST 通过唯一的格式版本 1 schema 在项目 Tiptap JSON 与 ProseMirror 文档之间转换，并 SHALL 保持可见字符、字符顺序、开头与结尾空段落、连续空段落、段落数量与顺序、支持的标题等级、列表类型与顺序以及粗体和斜体标记一致。HTML 或纯文本投影 MUST NOT 代替 Tiptap JSON 成为本子的项目事实源。

#### Scenario: 空本子往返
- **WHEN** 系统用有效空白 Tiptap 文档初始化一个本子并读取其保存文档
- **THEN** 读取结果仍是语义相同的有效空白文档

#### Scenario: 混合格式文档往返
- **WHEN** 系统加载包含中文、标点、emoji、两级标题、粗斜体和两种列表的有效文档
- **THEN** 编辑器导出的完整文档保留原有可见内容、顺序和支持格式

#### Scenario: 包含首尾和连续空段落的文档往返
- **WHEN** 系统加载在开头、结尾或正文之间包含多个空段落的有效文档
- **THEN** 编辑器导出的完整文档保留全部空段落、段落数量和原有顺序

#### Scenario: 项目保存写入结构化事实源
- **WHEN** 用户手动保存作品
- **THEN** 前端向后端提交 `draft` 和 `main` 两份完整结构化文档
- **AND** 系统不以 HTML 或纯文本字符串代替本子 JSON 文件

### Requirement: 外部粘贴只进入受控结构
系统 SHALL 按 `controlled-rich-text-paste` 能力处理普通粘贴，只接收可可靠提取的可见文字和本轮支持的结构与标记，并 MUST 丢弃或拒绝其它外部格式和内容。复制与剪切 MUST 保持用户选区的可见文字，并可提供本轮支持的受控格式表示。

#### Scenario: 从网页粘贴带格式内容
- **WHEN** 用户从网页或文字处理软件复制包含支持和未支持格式的内容并粘贴到本子
- **THEN** 编辑器只插入可可靠提取的可见文字和本轮支持格式
- **AND** 内部文档不保留外部样式或未开放结构

#### Scenario: 复制和剪切本子选区
- **WHEN** 用户复制或剪切本子中的一个选区
- **THEN** 剪贴板纯文本与用户实际选中的可见内容一致
- **AND** 受控格式表示只包含本轮支持的结构和标记
- **AND** 剪切只删除当前本子中用户实际选中的内容
