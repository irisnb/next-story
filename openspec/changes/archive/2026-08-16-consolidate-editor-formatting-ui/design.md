## Context

第三轮已完成全部文字与段落格式能力并归档。当前这些控件的入口四处分散：

- 顶部横排工具栏（`#format-toolbar`）：段落样式、粗体、斜体、无序/有序列表、清除格式、撤销/重做、「更多」菜单、格式抽屉开关。
- 右侧格式抽屉（`#format-drawer`）：字符格式组 + 段落格式组。
- 右键菜单（`#context-menu`）：剪贴板 + 格式命令 + 链接命令。
- 快捷键 + 查找替换栏（`Ctrl+F`/`Ctrl+H`）。

用户反馈「东一块西一块」：想排版时记不住功能在哪、找起来费劲。本轮只做 UI 整合与收纳，不改任何格式命令行为、文档格式、AI 写稿边界。

## Goals / Non-Goals

**Goals:**

- 把格式控件整合成「左侧竖排工具栏（高频）+ 左侧格式抽屉（全量分类目录）」的分层结构。
- 工具栏与抽屉自动隐藏，给正文更多呼吸感。
- 查找栏获得可见入口。
- 右键菜单精简，为后续用途留白。
- 新增编辑器「留白」调节，作为显示偏好。

**Non-Goals:**

- 不改变任何格式命令、选区规则、文档格式、AI 写稿边界。
- 不做选区气泡（AI 选区入口已占据选中文字附近位置）。
- 不做纸张页边距、分页、纸张尺寸、DOCX 导出（未来独立 change）。
- 本轮只做留白，不做写作背景板颜色（未来再议）。

## Decisions

### 1. 左侧竖排工具栏只放高频项

顶部横排工具栏改为左侧竖排，只保留高频布尔/开关型操作：粗体、斜体、下划线、删除线、无序列表、有序列表、段落样式下拉、撤销、重做、查找入口、格式抽屉开关。清除格式、字号/字体/颜色等低频或参数型操作全部移入抽屉。「更多」菜单撤销（高频项已直接可见，低频项进抽屉）。

### 2. 左侧格式抽屉按「字符 / 段落」两节可折叠

抽屉移到左侧，内部按 `character-formatting` / `paragraph-formatting` 两个已有能力边界分两节，各自可折叠（disclosure）：

- 字符格式节：下划线、删除线、字体、字号、文字颜色、背景高亮、清除字符格式。
- 段落格式节：对齐×4、行距、段前间距、段后间距、首行缩进、左缩进、右缩进、清除段落格式。

抽屉是所有格式控件的唯一分类目录；工具栏只是高频快捷。折叠状态在会话内保持。

### 3. 抽屉自动收起，工具栏为静态独立列

- 抽屉：鼠标移出抽屉区域即缓缓收起（`mouseleave` 触发，带过渡动画）；鼠标移到工具栏「格式」开关或再次点开关重新打开。
- 左栏（竖排工具栏）：静态独立列，常驻占位、正文从它右侧开始，不做自动隐去（原浮层式自动隐去会遮挡正文，测试后被用户否决，改为固定列）。
- 抽屉自动收起是显示层行为，不改变任何命令状态、选区规则或快捷键；AI 面板（右侧）不受影响。

### 4. 查找栏获得可见入口

工具栏放一个「查找」按钮，点击与 `Ctrl+F` 等效（打开查找栏并聚焦查找框）；替换仍由 `Ctrl+H` 或查找栏内的替换框触发。查找栏本身保持独立浮条，不并入格式抽屉。

### 5. 右键菜单精简

移除右键菜单里的下划线、删除线、清除字符格式、清除段落格式，只保留剪切、复制、粘贴、粘贴为纯文本 + 链接的打开/编辑/移除/创建。格式命令的唯一图形化入口收敛到左侧抽屉（键盘快捷键仍可用）。

### 6. 编辑器「留白」为显示偏好

新增编辑器正文四周留白的调节（预设档位：紧凑 / 标准 / 宽松三档），作用于正文容器（`.editor-notebooks`）的 padding，纯显示层。留白是应用级显示偏好，持久化到 `localStorage`（键如 `next-story.margin-preset`），不写入 `草稿本.json` / `正文本.json`，也不进入 AI 输入。默认档位为标准（2rem 留白，即用户认可的「正常」观感）；紧凑 1rem、宽松 3rem。

### 7. 明确不做

- 选区气泡：AI 选区入口已浮在选中文字附近，为避免冲突，本轮不引入 BubbleMenu。
- 纸张页边距/分页/纸张尺寸/DOCX 导出：与「导出」能力绑定，留待未来 change，本轮不碰文档事实源。

## Risks / Trade-offs

- [左侧竖排工具栏改变既有使用习惯] → 高频项全部保留在工具栏，低频项进抽屉，避免「常用功能反而更难找」。
- [自动隐藏导致「找不到入口」] → 左边缘 hover 唤起 + 抽屉开关常驻工具栏；过渡动画保证「缓缓」而非突然消失。
- [留白偏好用 localStorage 可能被清] → 显示偏好被清只是回退默认，无数据风险；若未来需要更稳，再迁到 Rust 侧应用设置文件。
- [抽屉与 AI 面板不再抢右侧] → 格式抽屉在左、AI 面板在右，二者不再争抢同一侧空间。

## Migration Plan

纯 UI 与显示偏好改动，无文档数据迁移。留白偏好新增，默认值对齐当前显示，无可见变化；`localStorage` 无键时回退默认档位。

## Open Questions

无。布局、左右、自动隐藏、右键精简、留白范围均已由用户逐项确认。
