## Why

应用当前使用的是脚手架自带的"默认灰"视觉（浅灰蓝边框 `#e2e8f0`、灰蓝按钮 `#4a5568`、圆角、柔和阴影），没有产品性格，也与项目已确认的视觉方向不符。项目方向文档（`.omo/二阶段-01-编辑器、项目结构与UI方案/二阶段文本编辑器及相关功能的探讨和确定.md` 二.6）已确定二阶段采用「全量新粗野主义」（Neobrutalism）作为视觉方向。本 change 把该方向落到现有应用 UI 上，让这个写作工具有清楚、有辨识度的外观，同时保持正文编辑区作为安静的视觉中心。

## What Changes

- 引入**设计令牌系统**（CSS 自定义属性）作为颜色、边框、阴影、圆角的唯一事实源，避免把视觉值硬编码散落在各处。这是本 change 的核心机制，也是"后续 UI 会继续迭代"的前提——后续调色、调边框粗细、调阴影距离只改令牌，不改散落值。
- 将应用从"默认灰"整体换肤为新粗野主义方向：纯白底、黑色结构线边框、硬边偏移阴影、零/小圆角。
- 确立配色体系：主色钴蓝 `#2743E0`（动作/选中/当前态）、辅助暖金 `#F0B429`（选区高亮/候选）、中性墨黑 `#171717` 与白、语义色（成功绿/危险红/提醒琥珀）。
- 建立视觉主次：文本编辑区框是全窗口焦点（最重的边框 + 阴影），chrome（顶栏/标签页/工具栏/AI 面板）依次更轻；选中/激活态统一用主色钴蓝，不用黑色。
- 布局结构（`index.html` 的 DOM 结构）与所有行为逻辑不变，纯视觉换肤。

## Capabilities

### New Capabilities

- `design-tokens`: 应用的视觉身份通过集中式设计令牌（颜色、边框、阴影、圆角）定义，并作为新粗野主义方向统一应用；选中态用主色、文本编辑区为视觉焦点。

### Modified Capabilities

（无——本 change 不改任何现有行为的 spec 级需求，纯视觉层。）

## Impact

- `src/styles.css`：主要改动目标，颜色/边框/阴影/圆角值全部迁移到 `:root` 设计令牌。
- `index.html`：可能需少量 class/属性补充以表达选中态（预计极小，不改 DOM 结构）。
- `tests/editor-layout-style.test.ts` 等样式相关测试：可能需更新以匹配新令牌。
- 参考渲染稿 `.omo/ui-direction-comparison.html`（方向确认用，非应用代码，不随 change 归档）。
- 无后端/Rust 改动，无 API/依赖变化。
